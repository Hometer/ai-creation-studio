## ✨ 这是什么

一套给**不懂代码的产品经理 / 学生**的开箱工具包。把它交给一个能操作你电脑的编码 AI（Claude Code、Cursor、Codex 等），贴一句启动句，AI 就带你从"一个想法"走到"上线产品"——写代码、跑测试、做界面、部署上线，全由 AI 完成；你只做少量"必须本人才能做"的事。

## 🎯 它解决什么问题

| 你的处境 | 这个工具包给什么 |
| --- | --- |
| 有产品想法，但不会写代码 | AI 替你写全部代码，你只做业务判断 |
| 网上教程太技术、太碎片 | 内置三份技术手册，AI 按阶段自动读取 |
| 不知道"做到哪算好" | 每个阶段有明确闸门和证据包，你能自己核对 |
| 卡在云平台、密钥、备案 | 上线阶段有"照着点"清单，注册/认证/开权限都有引导 |

## 🚀 快速开始（约 1 分钟）

1. 把整个文件夹放到你电脑上（压缩包先解压，**不要改里面文件**）。
2. 用一个**能读写文件、执行命令的编码 AI 工具**打开这个文件夹（网页版纯聊天 AI 不行）。
3. 在对话框贴这句话：

   ```text
   请读取项目根目录的 AGENTS.md，按其中"启动流程"开始。
   ```

4. AI 会根据你的情况自动走流程（有没有 PRD、是不是接着上次做）。之后每一步 AI 都会告诉你"下一步做什么"；看不懂就说"用产品语言再说一遍"。

> 📖 完整操作手册见 [开始看这里.md](./开始看这里.md)。

## 🧭 六个阶段

| 阶段 | 内容 | 你要做的 | 通过条件 |
| --- | --- | --- | --- |
| 0 PRD 体检 | 检查 / 补全产品需求 | 回答问题（≤5 个/轮，可回"按推荐"） | 补全清单全部关闭 |
| 1 技术适配 | 定技术方案 | 确认理解对不对、有无多出费用/范围 | 决策台账无影响本阶段的待定项 |
| 2 后端 MVP | 核心能力 + 真实验证 | 提供 Key、给真实结果打分、照清单验收 | 证据包已交 + 闸门全"是" |
| 3 正式前端 | 界面 + 移动端 | 给视觉方向、看代表页、真机走一遍 | 同上 |
| 4 上线 | 部署到云 | 注册/认证、控制台照着点、验收 | 验收清单全过 |
| 5 收尾 | 整理 + 删密钥 | 删云密钥 | 状态文件记录完成 |

每个阶段结束，AI 必须交**证据包**（截图 + 可打开地址/照着点步骤 + 是否表）。是否表有"否"就不能说完成。

## 🔒 内置的强制底线

这套规则卡约束 AI，你可以放心：

- 🔑 密钥不进仓库、不进前端、不回显
- 💾 数据可恢复，重启不丢
- ✅ 真实模型验证，不拿 mock 结果冒充
- 💰 涉及花钱的云资源，先告知费用再动手
- 🔐 用户只能看自己的数据
- 🛡️ 错误不泄露技术堆栈

## ❓ 常见问题

**要花钱吗？** 两处：模型 Key（按用量付费，AI 会帮你估）；上线云费用（上线前会估，创建前必须经你确认）。开发期可先不买 Key，AI 用模拟数据推进。

**必须企业认证吗？** 正式上线的默认方案需要云平台企业认证。没有的话，AI 先用临时方案上线并明确三条限制，认证办好后再切换。

**AI 说做完了，我怎么信？** 看证据包：截图 + 可打开的地址 + 是否表。有"否"就不算完成。

**可以中途换模型 / 换工具吗？** 可以。规则和进度都存在文件夹里（`docs/项目状态.md`），不依赖某个模型的内存。

## 小云雀本地运行

本目录另包含小云雀 AI 视频应用，位于 `docs/AI视频/xiaoyunque-main/xiaoyunque/xiaoyunque/`。2026-10-04 已完成一次现有代码运行检查，结果见 [运行报告](docs/evidence/阶段0/现有代码运行检查/运行报告.md)。现有应用目录保留，根目录已增加统一运行入口。

当前电脑已具备 Python 3.12、Node.js 22、ffmpeg，以及后端 `.venv` 和前端依赖。以下命令均从本项目根目录开始。

后端，在一个终端启动：

```bash
cd 'docs/AI视频/xiaoyunque-main/xiaoyunque/xiaoyunque/backend'
.venv/bin/python api_server.py
```

前端，在另一个终端启动：

```bash
cd 'docs/AI视频/xiaoyunque-main/xiaoyunque/xiaoyunque/frontend'
npm run build
npm start -- --hostname 127.0.0.1 --port 3000
```

打开 http://127.0.0.1:3000 ，应看到创意输入框和灵感示例。打开 http://127.0.0.1:8000/api/health ，应看到 `status` 为 `ok`。停止服务时，在对应终端按 Control+C。

验证方法：在后端目录执行 `.venv/bin/python -m pytest -q`；在前端目录执行 `npm run lint` 和 `npm run build`。初次运行报告记录了旧问题；最新整改结果为后端 42/42、前端回归 33/33、类型检查、全量 Lint 与生产构建通过。手机侧栏与顶栏已修复，见 [前端整改证据](docs/evidence/阶段2/前端整改/验收报告.md)。

当前模型密钥全部未配置，真实生成待验。在“设置”页配置选定平台密钥后才能进行真实生成；不要将密钥发到聊天或写入仓库。后端本地配置文件已由其 `.gitignore` 排除。本次未调用付费模型。
