# 配置说明

启动后在「设置」页配置自己的模型服务。安全配置保存在主应用后端本地，`config.yaml` 和秘密配置均被 Git 忽略。模型 Key 只供后端使用。默认后端 8000，前端代理可通过 `BACKEND_API_URL` 调整；真实生成需自行确认素材权利、费用与预算。

| 配置 | 位置 | 作用 |
| --- | --- | --- |
| 模型平台 | 设置页与 `backend/config.yaml.example` | 填写个人服务配置，真实调用按供应商计费 |
| BACKEND_API_URL | 前端进程环境变量 | 默认 `http://127.0.0.1:8000`，改端口时同步 |
| 运行数据 | 主应用 `backend/data/` 与 `backend/code/data/` | 本地持久化，不提交；完整备份范围见历史记录 |

## 本机数据与验证

主要代码保留在 `docs/AI视频/xiaoyunque-main/xiaoyunque/xiaoyunque/`，包含 `backend/` 和 `frontend/`。根目录 `scripts/project.py` 提供统一入口；本次保留该路径以兼容既有运行与验收脚本。

各项目端口可能重叠，分别运行时先停止自己启动的前一项目，或按各项目配置调整端口与代理。密钥、业务数据、模型文件、依赖和构建产物留在本机，不进入公开仓库。克隆仓库不会带入原电脑的模型配置、邀请码数据库或费用额度。
