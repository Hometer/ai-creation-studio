后端 434/434（原 377 全部保留，新增 57），前端 33/33、类型检查、全量 Lint 0 错误／0 警告、生产构建通过。并发分配、跨项目共用上限、上海跨日跨月、价格／预算／审核／素材变化、幂等、取消及存储损坏均通过。实际隔离 HTTP 服务连续三轮启动核对恢复；人工 task-demo 服务重启前后准备记录与额度相同。旧 SIM 任务账本、资产库和预检历史文件的字节摘要未变，未推进旧生成任务。

秘密检查：本地非空秘密字段 0，304 份源码文本秘密模式命中 0，17 个生产 JS 文件命中 0，无独立打包交付物。没有模型调用、素材外发、收费、云资源或新增正式前端。原 pytest 配置、DashScope 废弃和前端测试 DOM 属性提示保留，不删测试、不隐藏提示。

## 自行核对

1. 在项目目录打开终端，运行 `python3.12 scripts/project.py task-demo`。浏览器打开 http://127.0.0.1:8001/docs ，找到“万相报价、额度与样例准备（不收费）”。这是既有人工入口，不要在原用户项目录入本报告的演练额度。服务端口被占用时可使用 `--port 8002`，对应把以下地址端口改成 8002。
2. 浏览器打开 http://127.0.0.1:8001/api/wan-quotes/f88ffed508144858b3f2c885ec1b6cd2 ，勾选“美观输出”。看到金额 35、来源 offline_fixture、独立价格核验 false、执行 false 算对。20 分钟后 expired=true 并出现 QUOTE_EXPIRED 是预期；过期估算只能查看历史，不能确认准备。
3. 打开 http://127.0.0.1:8001/api/wan-preparations/d9471f362c8e4ba2aeb13fd0f02531db 。记录已为 cancelled，revision=2、active_planning_held_minor=0、submit_attempts=0、real_execution_allowed=false。后续否认已发生，因此 blockers 含 SAMPLE_REVIEW_CHANGED 和 PREPARATION_CANCELLED；跨日或过期还会增加对应提示。
4. 打开 http://127.0.0.1:8001/api/wan-budget ，看到 policy.source_kind=offline_fixture、日／月分配均为 0，实际消费 null、真实预留 false；这不表示账户实际消费为零，只表示本地分配已释放。
5. 打开 http://127.0.0.1:8001/api/wan-sample-reviews/28405e76cc394f02a675f75ef95bfaaa ，看到 accepted=false、rights_confirmed=false。操作者对素材权利的否认不会被价格或总体隐私规则覆盖。
6. 在服务所在终端按 Control+C，再运行同一 task-demo 命令，重新打开上述地址，记录与本地额度应保留。新电脑没有忽略的验收数据，可看仓库截图；这些编号是本机人工样例，不是秘密。

重新准备实际样例时，先查看既有计划及受控素材，核对平台账户报价与有效期，再在上述 /docs 录入价格与额度、逐计划审核并建立新报价；只有明确 preparation_only=true 的本地记录可确认。真实价格与实际额度尚未由产品经理选定，当前不需要填 Key。不要修改 JSON、清除记录或把演练数字当真实预算。价格／预算换版本或来源变化时重新核对；失效未取消的准备仍占原本地分配。

完整检查：在项目终端运行 `python3.12 scripts/project.py check`，看到五项“通过”算对。模块检查在后端目录运行 `.venv/bin/python -m pytest tests/test_generation_readiness.py -q`，本轮 57 项。备份保留整个资产库与会话目录；新记录为 generation-readiness.json，旧文件不迁移。人工目录在忽略的 data/generation-task-demo/，历史截图为本次检查时状态，实时接口会随到期／日期变化显示阻塞。
