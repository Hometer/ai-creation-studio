## 照着核对

本轮临时服务与浏览器已经停止；以下地址在重新启动后可打开。不需要配置 Key。

1. 在项目根终端运行 `python3.12 scripts/project.py task-demo`，打开 http://127.0.0.1:8001/docs ，看到人工演练标题。在“万相离线预检（不调用模型）”展开 GET 或 POST，可查看严格合同。端口占用时入口拒绝启动，不结束其他服务。
2. 打开 [输入通过的报告](http://127.0.0.1:8001/api/model-preflights/b867794a66a84d93b318082bb5898a93)，勾选“美观输出”。应看到 input_protocol_ready=true、real_execution_allowed=false、network_used=false、authentication_verified=false、amount_minor=null、currency=null。KEY_MISSING 和真实执行／适配／预算／样例核对等阻塞项仍在。
3. 打开 [旧 SIM 计划的报告](http://127.0.0.1:8001/api/model-preflights/f85ef95d071545e399ef250a0f53b545)，应为 input_protocol_ready=false，片段 issues 有 MODEL_NOT_ADAPTED，request_sha256=null。旧 SIM 模型不是万相模型，不能把人工演练结果当真实接入。
4. 打开 [无声计划的报告](http://127.0.0.1:8001/api/model-preflights/89ae6ede5d414081bb2232ef40b4e3f9)，应看到 SOUND_OFF_UNSUPPORTED、input_protocol_ready=false。镜头字段未作为平台参数透传，单独标记 SHOT_TYPE_NOT_SENT 警告。
5. 打开 [旧项目预算](http://127.0.0.1:8001/api/project/media-demo/generation-budget) 与 [旧完成任务](http://127.0.0.1:8001/api/generation-tasks/b079be04fc5a4e20947b67fe809ca7e6)，应仍为 SIM 结算 20／剩余 0，以及 succeeded／submit_attempts=1。不要点击 advance；GET 只读。
6. 在终端按 Control+C，重新运行同一 task-demo 命令。再打开步骤 2—5，报告编号、检查日期、请求摘要、任务和预算保持一致。本轮已经实际做过该核对。
7. 想再次生成预检报告，在 /docs 展开 `POST /api/generation-plans/{plan_id}/wan-preflight`，点 Try it out，plan_id 填 `662ec5a5a2f24f57951912da03598c64`，正文留空或 `{}`，点 Execute。应返回 201、新 report_id，input_protocol_ready=true 且真实执行 false。该计划为本轮用人工图片新建并本地确认的万相计划；旧 SIM 计划未改。POST 会追加一份本地报告，不会生成视频。
8. 停止人工服务按 Control+C。常规后端 8000 启动方式保留，同样有预检接口，但上述演练记录只在 8001 的独立目录中。

current 只说明计划／引用和脱敏配置分类与检查时一致，不会重新检查图像字节，也不代表认证成功。真正执行前还需重新预检、逐次核对样例权利和当前文件。更换非空 Key 为另一条非空 Key 无法由存在性识别；authentication_verified 始终 false。报告不包含 Key 指纹或原 Endpoint。

## 已确定与仍待验的边界

已确定接入准备目标为阿里云通义万相；首轮样例有权、非敏感、境内处理。总体隐私规则不代替每张素材的版权／真人授权审核；没有自动外发权限。模型输入规格依据 [万相官方图生视频协议](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference)，模型名称与公开参考价格依据 [官方模型信息](https://help.aliyun.com/zh/model-studio/wan2-7-i2v)，详情与参考样例费用放在本轮开发文档。公开原价没有接入代码成为真实报价，也不是已批准预算。

真实查询应使用平台 task_id；丢失平台编号的提交失联，按保守规则人工核对并禁止重发，不能假设可以用本地 request_id 找回。官方查询方式见 [异步任务管理](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks)。本轮只保存这个恢复合同，真实 submit/query/download、原生超时、账务与实际认证尚未实现，不能从预检通过推断真实端到端已通。

参考生视频、真实平台传输、后台 worker 和正式任务／资产页面不在本轮。首帧／首尾帧编译只在内存构造 data URI，无上传或保存请求正文；报告只保留输入摘要和元数据。SIM 账务与真实报价保持分离，未知实际费用仍为 null。
