## 自行核对

1. 在项目目录打开终端，运行 `python3.12 scripts/project.py task-demo`；浏览器打开 http://127.0.0.1:8001/docs ，找到“万相执行前检查（不联网、不收费）”。端口被占用时可用 `--port 8002` 并把以下网址端口改为 8002。本报告只使用独立人工数据，不在用户项目录入演练额度。
2. 打开 http://127.0.0.1:8001/api/wan-execution-checks/ee76bb5d0ee3458e88112289391257a6 ，勾选“美观输出”。本机保留样例已取消，因此 current=false，current_blockers 含 PREPARATION_CANCELLED；历史 inputs_compiled=true 表示检查当时编译过，不表示现在允许执行。真实执行必须为 false。
3. 打开 http://127.0.0.1:8001/api/wan-execution-checks/734905bd6f4842baa5fd4a6c35033b57 ，看到修订 2、inputs_compiled=false、request_sha256 为空、PREPARATION_CANCELLED 算对。这里 current=true 只表示该阻断报告仍对应当前条件；到期或跨日后显示 false 是预期。
4. 打开 http://127.0.0.1:8001/api/wan-budget ，日／月分配应为 0，actual_charged_minor=null、real_money_reserved=false。此数只表示本地准备分配已释放，不能推断阿里云账户消费。
5. 要自行检查同一人工准备，在 /docs 展开 `POST /api/wan-preparations/{identifier}/execution-check`，点 Try it out，identifier 填 `63d174113fb14d8e9c1a9ade18823296`，正文填 `{}`，点 Execute。看到 HTTP 201 的报告仍包含 PREPARATION_CANCELLED、inputs_compiled=false 和 real_execution_allowed=false 算对。201 表示保存检查成功，不是生成任务成功。不要填执行开关、Key 或额度。
6. 在终端按 Control+C 停服务，再运行同一 task-demo 命令，重新打开上述地址，历史和取消状态应保留。日期、价格或其他当前条件变化会增加阻断信息。新电脑没有被 Git 忽略的人工数据时，查看仓库截图与自动化检查即可；这些样例编号不含秘密。

完整验证：项目终端运行 `python3.12 scripts/project.py check`，看到五项“通过”算对。模块验证在后端目录运行 `.venv/bin/python -m pytest tests/test_execution_checks.py tests/test_wan_http_transport.py -q`，应为 88 项通过；本机 HTTP／HTTPS 自动化使用人工数据，不发平台请求。记录为私有资产目录 execution-checks.json，备份整个资产库与会话目录，不手改 JSON、删历史或移除锁文件。
