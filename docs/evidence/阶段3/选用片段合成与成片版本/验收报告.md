## 自己核对

1. 打开 http://127.0.0.1:3019/projects/composition-demo/compose 。人工蓝色2秒有440Hz音调、黄色1秒静音；项目目标3秒。
2. 每个分镜片段选择对应归档视频，点上移／下移确认顺序。缺少片段时“准备合成计划”不可点。点“准备合成计划（不执行）”，右侧出现全部片段、固定版本、顺序、总时长与输出规格；未勾选时不能合成。
3. 核对后勾选本次确认，点“确认并在本机合成”；完成后播放并下载MP4。历史#1为蓝→黄、#2为黄→蓝，都可继续打开。下载的[人工蓝黄三秒成片](人工蓝黄三秒成片.mp4)为实际浏览器下载，1280×720、3秒。
4. 实际项目从 http://127.0.0.1:3000/ 的“素材与版本”进入“合成与导出”。所选视频时长与整片目标分别显示，不拉伸目标、不跳过缺段。上游已改变的候选逐段确认仍保留旧版本；再次收费生成仍走原费用确认。
