# 生成计划界面验收记录

2026-10-05。按先文档、开发、验证后本地提交执行。本文记录阶段 3 第 5 子阶段的工程交付；真实模型、手机真机和业务验收保持待验，不宣布整个阶段完成。

## 可以核对的结果

项目素材页新增“生成计划”入口。可新建首帧、首尾帧、参考图计划，查看所有已保存片段、分镜、固定图片与文字版本。保存后需单独勾选核对并确认本地输入，再手动检查；费用始终待确认，真实执行保持关闭。仅出现新版时仍使用固定版本；引用修改后历史计划标为受影响、不能继续检查，新计划可使用当前引用。

确认、刷新与重启后的记录由既有后端实际保存。表单一次创建一个片段，既有多片段历史完整显示。保存采用后端当时的引用状态，确认前需核对返回计划的实际固定内容；没有并发编辑的前端强制锁。新建不自动确认、检查、创建任务或调用模型。

## 直接打开与照着点

主应用为 [本机创作工作室](http://127.0.0.1:3000)。打开已有项目 → 顶部“素材与版本” → “生成计划”。读取和查看不会执行模型。有分镜及适用图片引用时可新建；否则先回项目准备分镜，再在素材页绑定引用。原五个项目保留。

本轮另保留独立 [人工生成计划预览](http://127.0.0.1:3001/projects/media-demo/plans?plan=6da5119f0dda4561a8a4699e534ce5af)。标题、图片和模型名称都明确人工，无模型调用。此服务只支持素材／计划验收，不用于原工作台生成。

1. 默认参考图计划显示蓝色 v2、“已确认本地输入”和真实费用待确认。点击“检查本地输入”，应显示 1 个片段、1 张固定图片，未创建生成任务。
2. 从列表选择首帧或首尾帧旧计划，应看到“素材引用已切换”，仍保留黄色 v1；“检查本地输入”禁用。
3. 点“新建计划”，选择输入方式、图片引用用途及可选文字设定，点“保存计划”；先核对固定版本，再勾选说明并点“确认本地输入”。保存没有自动确认。
4. 刷新详情地址，应仍选中该计划，确认记录仍在。切换记录后用浏览器前进／后退可恢复选择。
5. 点“重新读取”只刷新数据。服务断开时显示读取失败并保留上次记录，写操作关闭；恢复服务后手动重读。

技术复现：根目录 `python3.12 scripts/project.py plan-center-demo` 启动 8001，数据独立在忽略目录 `data/plan-center-demo/`，后续启动不重新播种。前端目录在主前端停止后可用 `BACKEND_API_URL=http://127.0.0.1:8001 npm run dev -- --hostname 127.0.0.1 --port 3001`。本轮为同时保留主生产预览，人工前端使用 `/tmp/plan-ui-frontend/` 副本和同一依赖，以 webpack 启动；无产品依赖／构建器替换。8001 不能与其他人工服务同端口并行。实际模型路由、费用／任务／执行路由没有挂载到该演练服务。

- 前端新增 27 项，最终 141/141；类型检查、Lint（0 错误／警告）和生产构建通过。既有测试保留。

- 四宽度 390／768／1280／1440，确认详情、创建表单、失效提示、离线保留及生产空列表共 20 项状态检查，没有页面横向溢出；表单／确认页控件未超边界、图片正常。移动宽度不代替手机真机。
- 实际页面分别创建三种输入模式。未经勾选确认按钮禁用；确认、手动检查、刷新恢复通过。模拟服务器保存成功后回复丢失，实际写入仅 1 次、表单保留、重复保存被阻止；重读找回记录。使用真实引用升级接口后两份旧计划失效，新参考图计划正常。
- 修复浏览器历史状态的内部信息保留；前进／后退恢复详情，监测没有额外计划 GET，没有 POST。断线时保留三份旧记录并禁用写操作；恢复后手动检查再次通过。
- 独立 HTTP 服务三次真实进程启动，后两次从同一目录恢复：三份计划响应一致，四个持久化 JSON 的哈希保持，确认和影响检测一致，没有重播、生成任务或平台请求。
- 本轮根 data／后端 data 开工快照 135 个非日志文件无改写／缺失；额外对照上一轮包含主会话的 141 个非日志文件基线仍一致，原五个项目保留。仓库候选与生产静态文件敏感配置匹配为 0，配置与运行数据未追踪。没有新增 Key、依赖或云资源。
