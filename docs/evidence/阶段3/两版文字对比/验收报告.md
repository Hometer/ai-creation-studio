# 两版文字对比验收报告

日期：2026-10-05。阶段 3 第 11 子阶段工程结果已交付，按先开发文档、再代码、验证后本地提交执行。真实模型、真机、业务及整个阶段尚未验收，不宣布阶段完成。

## 自己核对

打开 [独立人工版本页](http://127.0.0.1:3007/projects/comparison-demo/revisions#revision-comparison)。这是人工文字与结构，不代表模型生成；对比只读取，页面原有保存／恢复需另行明确确认。

1. 点“两版对比”，选“剧本版本”，左版 v1、右版 v6，点“查看两版差异”。应看到五处变化，包含标题、梗概、制作批次的文字变数字、说明删除及新增空值。
2. 点“交换左右”，应变成 v6 → v1，左右值和增删方向反转。选 v4 → v6 应显示不同记录但内容相同；选 v6 → v6 应显示同一版本。
3. 选“分镜版本”，比较 v2 → v8。应显示第一片段结构与镜头变化，下方提示原 seg-1 和新 seg-new 的待核对镜头；没有重生成媒体。
4. 刷新页面，应保留所选版本并重新读取结果。地址中的非法／失踪／跨阶段版本会报错，不偷偷换版；重新选择有效同阶段版本可继续。
5. 在上方“定向修改”选择一处文字，填人工草稿，点“两版对比”或交换左右，草稿应保留。“重新读取版本”先提醒放弃草稿，取消保持草稿；确认且读取成功才清空。
6. 缩窄窗口到手机宽度，选框与左右文字纵向排列，按钮可点，无横向溢出。

只核对这份人工样例。主应用 [任务中心](http://127.0.0.1:3000/tasks) 保留生产预览；主库五项目可从原入口进入版本页。已有旧生成入口仍可能在配置有效 Key 后调用模型，本轮仅查看版本，不发起生成。

## 启动与复验

从仓库根目录运行 `python3.12 scripts/project.py comparison-demo`，默认后端 8007，人工数据在忽略的 `data/comparison-demo/`，重启不会重新播种已有会话。服务仅挂本地版本、资产、计划及只读导航，无模型执行路由；同页修改／恢复仍是持久化写入。端口已占用时使用现有服务，不停止其他演练。

前端使用已准备的独立目录：`BACKEND_API_URL=http://127.0.0.1:8007 npm --prefix /tmp/revision-comparison-frontend run dev -- --webpack --hostname 127.0.0.1 --port 3007`。临时目录被清理时由开发者重建副本；与主前端分开构建目录，避免覆盖 `.next`。人工预览已保留。

根目录完整检查为 `python3.12 scripts/project.py check`。单模块后端在应用 backend 运行 `.venv/bin/python -m pytest tests/test_revision_comparison.py -q`；全量 `.venv/bin/python -m pytest -q`。前端运行 `npm test`、`npm run typecheck`、`npm run lint -- --max-warnings=0`、`npm run build`。生产预览需先构建，再 `npm run start -- --hostname 127.0.0.1 --port 3000`，对应主后端 8000。
