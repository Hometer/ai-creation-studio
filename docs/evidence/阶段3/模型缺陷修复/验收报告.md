| A15 空响应重试失控 | GPT／Gemini 文本及视觉的每次请求都计入 max_attempts，包括空 choices、None、空白和无效结构；关闭 SDK 隐式重试；无末次等待；认证／参数错误和明确额度不足不继续重试；临时错误尊重可解析的 Retry-After，超过调度预算则停止 | 四客户端最多一次／两次的调用计数符合限制；失败后成功、剩余超时缩短、预算不足、迟到结果拒绝及初始化失败均通过；实际 SDK 人工传输一次 500 后一次成功，共两次 HTTP 调用 |
| A16 TLS 降级 | 下载始终 verify=True，证书失败立即停止，不屏蔽警告；响应关闭，流中断有限重试；文件先写同目录临时文件，完整完成后原子替换 | 证书失败仅一次请求，无降级；网络中断不覆盖旧文件、不留下半成品；超时后成功、404／500 和代理参数保持均通过 |
