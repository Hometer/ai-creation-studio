# 文字备份只读预检 · 验收证据

日期：2026-10-06。按先文档、开发、验证、本地提交交付，不推送。工程检查通过，真实模型／业务／真机、A07 与整个阶段仍待验或开放。

## 自己核对

打开 [八条人工历史的检查页](http://127.0.0.1:3013/projects/comparison-demo/revisions#revision-import-precheck)。文件都只送到本机后端，不保存或恢复项目。

1. 在上方“文字版本导出与备份”点“下载 JSON 备份”；回到“检查文字备份”，点文件选择控件，选择刚下载的 JSON。此时尚未上传，也不应出现报告。
2. 点“检查这份备份”。看到检查通过和来源 comparison-demo；剧本应为 4 个字段／5 条版本，分镜为 5 个字段／3 条版本，两阶段与当前正文相同。展开历史摘要应有 8 条记录，尚未恢复或覆盖项目。
3. 在本页编辑区临时改一句、生成预览并勾选，但不点保存；再次检查，输入、预览和勾选应保持。检查按钮不会保存编辑内容。
4. 选择 TXT 或错误 JSON 检查，看到拒绝／错误，旧报告清除、文件选择保留。断网后检查失败，联网再手动点检查应恢复报告；不会自动重发。刷新页面后需重新选择文件再检查。
5. 打开 [空项目](http://127.0.0.1:3013/projects/revision-empty/revisions#revision-import-precheck)，下载本项目 JSON 检查，应为零字段／零版本。若选择 comparison-demo 的文件，应看到来源不同的提示及不同正文比较，无覆盖按钮。

可直接使用这两份实际浏览器下载文件：[人工文字备份](人工文字备份.json)（15,445 字节、8 条历史）、[人工空文字备份](人工空文字备份.json)（451 字节、零历史）。只含人工演练文字，不代表真实模型效果。摘要是内部一致性校验，不是来源签名；文件和摘要同时修改仍可能通过，不能据此判断文件可信。

独立后端／前端 8013／3013 保留，数据在忽略的根 `data/revision-import-precheck-demo/`。服务停止后根运行 `python3.12 scripts/project.py revision-import-precheck-demo`；另一个终端进入 `/tmp/import-precheck-frontend`，运行 `BACKEND_API_URL=http://127.0.0.1:8013 npm run start -- --hostname 127.0.0.1 --port 3013`。独立构建已保留，临时目录丢失时由开发者按 README 重新准备，不改主服务代理。

## 已验证的结果

分别运行全量后端 1020/1020（新增 38）、前端 464/464（新增 39）、类型检查、零警告 Lint、主生产构建与独立 webpack 构建，均通过。根 check 仅是复验入口，本轮没有另外执行它。测试覆盖真实导出原始文件、空／历史／不同来源／未归档、必填格式标签／摘要／编号／恢复关系／当前引用、重复键／非法数值／嵌套深度／节点数／各容量上限、请求流式限长、只读零写入、严格报告与文件绑定、超时／取消／手动重试。既有 pytest 配置和 SDK 两条警告保留，A07／依赖告警继续开放。

实际浏览器通过本地 HTTP 验证：真实下载再选择，选择零请求，键盘明确检查只发一次；展示两阶段范围和全部 8 条历史。检查前后未保存文字／预览／勾选保持。错误 JSON、缺失格式标签、摘要不一致、TXT、64 MiB 加一字节文件拒绝；失败清除旧报告并保留选择。人工调整正文并同步摘要的文件用于展示“不同正文／未归档”，没有写项目，且明确不能证明来源可信。

真实 CDP 断网后选择保留，联网手动重试成功。浏览器通过注入过期 expected_token 得到真实后端 409，旧报告清除；这不是两窗口实际改正文演练，后端自动测试另实际保存目标后验证旧 token 冲突。检查中暂缓真实服务的成功响应，文件／按钮锁定，再次键盘操作无重复请求；重新读取版本后释放迟到响应，旧报告被忽略、文件保持，之后可手动再检查。没有提供假成功或假模型结果。

刷新需要重选文件，普通刷新后零控制台错误。320／390／768／1024／1280／1440 六宽度均无横向溢出，关键操作的几何边界在视口内；主生产空项目 1440／390 通过。宽度模拟不替代真实手机验收。

独立后端实际退出重启，两项目工作区／JSON 导出／预检共六组响应逐字节一致，四个演练文件保持；重启后重新检查实际下载文件成功。原 211 个保护文件无改写或缺失，主库五项目实际读取工作区、下载 JSON 并预检成功，两阶段与正文相同。预检未新增业务记录，上传文件和报告不持久化，本页文件选择不属于服务恢复状态。仓库与两份生产构建提交前脱敏扫描通过，会话和私有配置未跟踪，未输出配置值。
