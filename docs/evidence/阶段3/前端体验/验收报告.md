## 照着核对

1. 在浏览器打开首页，看到深色创作工作室、太空灵感封面、故事输入和四个工具入口。点击首页上方“探索灵感”，选择“治愈”，应只显示猫咪封面；点击封面，文字填入输入框并获得焦点。
2. 修改故事，普通 Enter 应换行。点击“生成配置”可查看原风格、比例、分辨率和模型选择。只点击“保存创作草稿”；成功后在“我的项目”看到真实新记录和“创作草稿”，应是 0/6 阶段。本轮不点击逐步创作、一键生成、重新生成或工具页启动任务。
3. 在“我的项目”输入不存在的关键词，应看到“没有找到这个故事”；点击“查看全部项目”恢复列表。点击“管理”，打开删除弹窗，按 Tab／Shift+Tab 应在两个按钮间循环，按 Escape 或取消返回原删除按钮；验证过程中不要确认删除原有项目。
4. 打开保留的人工草稿：[项目工作台](http://127.0.0.1:3000/?session=a1998899838147b6a644fd5c6dd47ce3)。应看到剧本阶段“等待生成”，不是已生成的结果。刷新应回到同一项目；返回首页仍能找到它。
5. 用手机宽度查看首页，菜单能打开、所有工具可达，Escape／关闭后不残留遮罩；工具入口进入各自已有页面。未提交文字离开页面不会自动保存，需要先保存草稿。

新人工验收项目已保留于真实本地会话库，未纳入 Git。原有两个项目未删除、原始文件哈希不变。服务真实停止并重新启动后，人工草稿完整状态与保存时一致，六业务阶段 pending、init completed、产物 0；没有模型请求。
