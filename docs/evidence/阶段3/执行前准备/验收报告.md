# 执行前准备界面验收报告

2026-10-05，阶段 3 第 6 子阶段工程交付。按先文档、开发、验证、证据、本地提交执行。真实模型继续后置；本报告证明真实本地持久化闭环，不代表模型效果、平台认证或真实计费已验收。

## 本轮交付

生成计划详情新增“查看执行前准备”。页面保存人工价格依据、所有项目共享的本地额度、逐计划素材声明、固定估算、本地准备／取消和手动检查。当前与历史、占用与释放、估算与未知实际费用分别显示；记录通过后端保存，刷新和重启恢复。新增一个按计划只读工作区接口，在既有事务锁内读取历史，不新增模型或任务执行接口，不迁移旧存储。

人工界面使用正式的本地后端服务，图片是程序制作色块，价格 720P 0.07 元／秒、1080P 0.11 元／秒为人工验证输入，不是官方或实际账户报价。本地确认不能授权真实发送，也不能授权旧生成入口。

## 可以直接打开核对

- 主应用：http://127.0.0.1:3000 ，项目 → 素材与版本 → 生成计划 → 查看执行前准备。
- 独立人工预览：http://127.0.0.1:3002/projects/media-demo/plans/2fabd01465f243cbbebe7bc75b1dea28/preparation?preparation=f725d7a3139c434589369c6fbcddf0e2 。应看到一份固定在图片 v2 的计划、本地估算 0.35 元、准备和本地检查历史；实际费用待确认、真实执行未开放。
- 受影响历史：http://127.0.0.1:3002/projects/media-demo/plans/638355ff7fd34b369b92abfeaeaf3249/preparation?preparation=7c8a0343ceb34249b8cf37a134c39b60 。应看到旧计划引用已变化、历史检查需重核对，仍保留本地分配，可明确取消。另有一份已取消准备可从列表查看。
- 不支持模式：http://127.0.0.1:3002/projects/media-demo/plans/c879fa0ce0c44fdaa0822925f14874d4/preparation 。参考图计划保留，不自动改成首帧；当前适配无法估算，金额待确认，准备被阻止。

记录编号不是秘密。估算会在保存后最多 20 分钟自然过期；到期会显示阻断，不能继续保存准备。历史分配不会自动释放。如需重新核对，先点“取消本地准备”、确认释放，再点“重新估算并保存”，核对金额和声明后勾选仅保存本地准备。三项声明的界面勾选在保存后清空，历史声明仍保留，不代表声明丢失。

## 照着点

1. 打开人工预览，看上方人工价格和“所有项目共享”的额度，确认实际费用显示待确认。点击“核对固定版本”可回计划页看图片 v2。
2. 回到准备页面，向下看已选记录和当前检查。刷新页面，准备编号和检查记录应保留，真实执行仍未开放。
3. 点击“取消本地准备”，确认弹窗；应看到已取消、当前本地分配 0 元，历史估算仍为 0.35 元。查看上方可分配额度，应增加同样金额。
4. 点击“重新估算并保存”，核对估算与额度；勾选仅保存本地准备，保存后应自动打开新记录。点击“检查本地准备”，应保存新检查，仍不产生真实任务或费用。
5. 若要核对声明阻断，可在当前计划保存三项均未勾选的声明，再重新读取；已有准备条件会变化，本地额度仍占用。重新核对三项并保存后，旧准备不会被偷偷替换，新准备需新估算与明确操作。
6. 打开受影响历史，应看到修改原因、历史检查和取消入口，保存新准备被阻止。打开不支持模式页，未知金额不得显示为免费。

主后端 8000、主生产前端 3000、人工后端 8002、人工开发前端 3002 保留供核对。人工后端启动为根目录 `python3.12 scripts/project.py readiness-center-demo`；数据在忽略的 `data/readiness-center-demo/`。其他演练使用 8001，互不覆盖。人工前端使用独立源码／构建副本，构建时同源代理指向 8002；主前端仍使用原生产构建，不共享 `.next`。
