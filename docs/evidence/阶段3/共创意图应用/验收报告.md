# 共创意图应用与版本保存验收报告

日期：2026-10-05。先写第 14 子阶段开发文档，再开发、验证和本地提交。工程检查通过；真实模型、业务、真机和整个阶段 3 继续待验，没有宣布阶段完成。

## 本轮结果

已确认且依据有效的请求，在共创页人工填写所选字段的新文字，核对修改前后及影响，勾选后保存正文、文字版本和请求关联。后端固定字段范围，一次请求只应用一次；意图确认与正文保存仍是两次独立的人工决定。修改保留要求的含义由用户核对。撤回请求保留已有文字版本，需要回退时去文字版本页单独预览确认。

未确认、已撤回、依据过期、正在执行的项目和篡改预览不能应用。保存失败保留输入并暂停写入；回复丢失按请求编号读取关联找回，不自动重发。旧编辑、回退与导出功能保留。未保存文字仍只在当前页，刷新或确认离开会丢失；草稿持久化留到下一轮。

## 产品经理照着点

1. 打开 [独立人工预览](http://127.0.0.1:3010/projects/comparison-demo/co-creation)。本轮保留五轮请求、六次决定、三个应用关联和十一条文字版本，全部是人工样例，不代表模型效果。
2. 点“第 5 轮 · 分镜 · 意图已确认”。在“修改后的文字”填与原文不同的新台词，例如“一起点灯，我们坚定地等最后一班渡船。”。
3. 点“预览这次修改”，看到修改前后各一段文字和 seg-new 镜头 1 的核对提示算对。未勾选前保存按钮不可用；继续编辑文字会清掉旧预览和勾选。
4. 核对“必须保留”、前后文字和影响，勾选后点“保存文字并关联请求”。看到新的版号及“查看关联文字版本”算对；点链接可看到对应版本，刷新共创页仍保留关联。此步骤会在独立样例新增第十二版，不改主库。
5. 第 1 轮显示“依据已变化”，不能应用；第 2 轮显示“已撤回 · 已保存版本”，仍能看到第九版。第 3 轮关联第十版，第 4 轮关联第十一版。任何请求应用一次后都不能再次应用。
6. 看到“保存结果尚未确认”时，保留输入，点面板里的“重新读取关联与版本”。发现关联即查看原版本；尚未发现时重新核对并预览，页面不会自动重发。

服务停止时，从项目根运行 `python3.12 scripts/project.py co-creation-apply-demo`，默认后端 8010；人工数据只在忽略的 `data/co-creation-apply-demo/`。本轮独立前端生产预览 3010 已保留；该临时副本不在 Git。长期恢复使用 README 的独立前端步骤。主应用后端 8000、前端生产预览 3000 已更新并保留。
