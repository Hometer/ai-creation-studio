# 任务中心验收报告

日期：2026-10-05。顺序为适配声明／开发文档 → 开发 → 验证 → 本地提交。模型后置，本轮没有模型请求、付费或素材外发。本轮工程检查通过，整个正式前端阶段及业务／真实模型验收仍开放。

## 可以直接查看

主服务 [任务中心](http://127.0.0.1:3000/tasks)，保留本地生产预览 3000 与后端 8000。人工服务和自动验收浏览器已停止。

1. 在侧栏点击“任务中心”，看到已有五个项目流程。点击“项目流程”或改变“全部状态”，列表会按条件变化。
2. 搜索“素材”，看到两个明确标注人工验收的项目。点击“素材管理”记录，看到待开始、已完成 0／6 阶段、所属项目和原编号。
3. 点击“打开项目”，回到原六阶段工作台；回任务中心点击“素材与版本”，原素材仍可读取。打开这些页面不自动执行阶段。
4. 点击记录后刷新浏览器，详情仍按地址里的编号找回。搜索一个不存在的名称，看到无匹配，点击“清除筛选”恢复列表。
5. 当前主库没有新生成任务，“本地生成任务”可以为空，不能把已有草稿称为模型生成。下方截图展示的排队、处理、失败、等待和视频属于隔离人工验收。

人工环境独立在忽略目录 `data/task-center-demo/`，重启保留样例；重现方式在 README“任务中心”。此环境只验任务中心，原工作台跳转使用主服务。没有要求产品经理配置 Key、创建目录或云资源。

## 核对结果

- 后端 558/558 全量通过；人工入口响应注解补齐后定向 7/7 复验。前端 102/102、类型检查、Lint 0 错误／0 警告、生产构建通过。原测试保留。
- 390／768／1280／1440 下列表、等待详情、无匹配、归档结果共 16 项检查通过；生产版本另复查四种宽度。无横向溢出，移动主区域宽度正确，操作控件至少 44px，移动菜单 Escape 关闭且焦点返回。
- SIM 一秒视频实际播放并下载；下载 1,894 字节与私有归档 SHA-256 一致，刷新恢复同一个结果。未知费用不显示零元，SIM 不换算人民币，固定阶段百分比不冒充模型进度。
- 人工任务库故障时只该来源失败，原成功结果和旧快照保留；首次失败显示暂未读到，不称为空。实际停止人工后端时四来源失败仍保留七条记录，刷新首次读取显示服务问题，恢复服务后重新读回原编号与结果。
- 两轮实际人工服务重启后四个 SIM 任务、两个人工专项记录、一个人工项目和归档媒体恢复；全部 14 个验收文件字节一致。读取、筛选、详情与恢复不增加平台提交／查询次数，不重播初始化步骤。
- 主后端实际重启后五个原项目可读，任务中心、原工作台和素材页面联调通过。主库已存在的 12 个项目／资产／引用／媒体文件哈希不变，没有删除或迁移用户数据。
- 新增只读全库接口包含已无所属项目的历史，读取不写任务／费用状态；坏库返回统一错误并保留原文件。尚无可靠统一取消／重试合同，页面不提供这两项操作。
- 源码／版本管理和前端产物的密钥检查通过，私有素材、验收数据、日志、`.env` 与构建产物均排除在提交之外。
