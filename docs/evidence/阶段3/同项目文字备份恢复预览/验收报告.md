# 同项目文字备份恢复预览 · 验收报告

日期：2026-10-06；阶段 3 第 18 子阶段。先开发文档，再开发、验证、本地提交。本轮工程结果已交付；真实模型、业务、手机真机和整体阶段继续待验，不能据此宣布整个阶段完成。无供应商调用、素材外发或新增费用。

## 照着点验证

1. 打开 [人工文字版本页](http://127.0.0.1:3014/projects/comparison-demo/revisions#revision-import-precheck)。若服务停止，开发者按 README 本子阶段启动方法恢复服务，不需要产品经理找手册或改文件。
2. 把 [人工旧文字备份.json](人工旧文字备份.json) 保存到电脑；在“选择 JSON 文字备份”中选择它。选择不会自动请求；点“检查这份备份”，应看到来源 comparison-demo、八条历史版本，以及与当前正文不同。
3. 点“预览恢复当前文字”。应显示合计两处差异：当前标题“人工备份之后的新标题”对备份标题“最后一班渡船 · 人工第二版”；当前镜头“人工备份之后的新镜头”对备份镜头“青年把灯交给守望者。”。左侧当前正文，右侧备份拟恢复文字，展开条目可核对完整文字、类型与可能受影响镜头。
4. 页面显示“尚未写入”，当前仍十条版本。没有实际恢复按钮，备份历史不会导入。当前页面输入、普通修改预览和确认勾选不会因恢复预览被替换。
5. 上方下载当前 JSON，再选择、检查、预览，应显示无需恢复。刷新需重新选择检查；换文件、重新检查或重读版本会清掉旧恢复预览。
6. 打开 [空项目](http://127.0.0.1:3014/projects/revision-empty/revisions#revision-import-precheck)，选择 [人工空文字备份.json](人工空文字备份.json) 后检查、预览，应显示两阶段零字段、零历史、无需恢复。该页选择 comparison-demo 旧备份可检查来源，但恢复预览禁用。

两份样例是本轮实际浏览器下载的人工文字备份：旧备份 15445 字节／八版本，空备份 451 字节／零版本。先下载旧备份，再用现有人工保存接口修改标题和镜头，形成十版本；不存在冒充真实模型验证。项目状态是本轮独立本地演练状态，不是新目录自动创建后的保证值。

## 已验证行为与界限

- 完整结构差异包含新增／移除、空字符串、null、文字转数字；结构演练文件为人工调整并重算内部摘要，不能作为可信来源。当前／备份两份分镜的保守影响范围均展示，不表示素材或计划已重做／审核。
- 实际断网失败清掉旧恢复预览，文件、预检范围和未保存编辑保留；手动重试成功，无自动重发。
- 浏览器向真实服务器注入备份中的旧 token，得到 409 拒绝；不是双窗口演练。后端自动测试另在实际保存正文后验证旧 token 冲突。不同来源返回 422；人工持久运行状态返回 409，界面均禁用预览。运行状态样例无真实后台任务、模型或 worker。
- 等待真实服务器响应时，文件与两按钮锁定，重复键盘操作仅一次请求；重新读取版本后再释放真实响应，迟到报告被忽略，文件保留而旧报告清除。未用伪造成功响应替代服务器验证。
- 六宽度 320／390／768／1024／1280／1440 无横向溢出、控件可达；窄屏前后值纵向，桌面两栏。主生产空项目 1440／390 通过，普通刷新与重新预览控制台错误为零。手机真机未验收。
- 实际 HTTP 服务退出重启，三个样例各工作区／导出／预检／预览共十二组状态与响应一致：十一组 200、一组预期执行中 409。五个演练文件和原 216 个保护文件无改变或缺失；十版本、旧备份两处差异保持。主库五项目自己的实际当前导出／预检／恢复预览全部通过、零差异。
- 后端全量 1042/1042（新增 22），定向旧预检＋新预览 60/60；前端全量 509/509（新增 45）；类型、零警告 Lint、主与独立生产构建通过。既有 pytest／SDK 提示、A07 和开发依赖告警保留；无真实模型效果证据。
- 文件名、实际 JSON 类型、64 MiB 文件和严格 v1 结构／摘要／内部关系校验继续生效；两阶段最多 2000 差异、完整响应最多 8 MiB，超限拒绝、不截断。文件／报告仅本页和请求内存，不保存上传文件或创建恢复记录。摘要不能证明来源可信，预览不等于恢复授权。
