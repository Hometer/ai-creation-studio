## 自己核对

打开 [第三轮人工历史草稿](http://127.0.0.1:3012/projects/comparison-demo/co-creation?intent=cfbc464f920845208b73f7a11a2265aa)，选择“第 3 轮 · 剧本”，向下找到“修改后的文字”和“已保存草稿”。编辑框应是第二份梗概，展开历史选择第一份，看到多行全文；编辑框保持第二份。

1. 点“载入这份草稿到编辑框”，应载入所选全文，同时清除旧预览和确认。尚未保存到后端，刷新仍恢复最近已存草稿。
2. 点“保存修改草稿”，看到保存成功后刷新，新文字应恢复；展开历史会多一条记录，原两份仍可选择。
3. 试改一句但不保存，选另一份历史再点载入，在提示中取消，刚才输入应保持；再次载入并确认才替换。若已有预览，取消保留预览，确认载入清掉预览与勾选。
4. 正式应用仍要“预览这次修改”，核对前后文字、保留要求和影响，勾选后再点“保存文字并关联请求”。此步会改人工演练正文，只在确实希望应用时点。
5. 第 1 轮已关联第 9 版，第 2 轮为旧依据，两轮可逐份查看历史（包括空白），不显示可写载入按钮。两窗口基于旧记录保存会提示变化；点“重新读取草稿与版本”后，当前输入和所选历史保持，再手动核对。

独立前后端 3012／8012 保留，人工数据在根 `data/co-creation-draft-history-demo/`，不代表模型效果。停止后根运行 `python3.12 scripts/project.py co-creation-draft-history-demo`；另一个终端进入 `/tmp/co-history-frontend`，运行 `BACKEND_API_URL=http://127.0.0.1:8012 npm run start -- --hostname 127.0.0.1 --port 3012`。独立构建已保留；临时目录丢失时由开发者按 README 重新准备，不改主服务代理。
