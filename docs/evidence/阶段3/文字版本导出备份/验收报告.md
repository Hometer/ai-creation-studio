# 文字版本导出与备份验收报告

日期：2026-10-05。阶段 3 第 12 子阶段工程交付。先写开发文档，再开发、验证与本地提交；不推送。真实模型、实体手机、业务和整个正式前端阶段继续待验，本报告不宣布阶段验收完成。

## 照着验证

1. 打开 http://127.0.0.1:3008/projects/comparison-demo/revisions#revision-export ，看到“导出与备份”、八条已归档版本及两个下载按钮算对。全部内容是独立人工样例。
2. 点“下载 JSON 备份”，在浏览器下载目录打开文件，看到 `format: text-revisions`、当前两阶段正文及八条 `versions` 算对。再点“下载可读 TXT”，看到当前正文、每条历史及完整 JSON 结构算对。下载提示仅表示文件已交给浏览器，不承诺保存位置。
3. 到编辑区选一个文字字段，输入一段草稿，然后下载。草稿仍在输入框、下载文件仍为已保存正文算对。无需保存草稿；离开或重新读取版本仍会提示是否放弃。
4. 可打开 http://127.0.0.1:3008/projects/revision-empty/revisions#revision-export 看空项目，或 http://127.0.0.1:3008/projects/manual-edit-demo/revisions#revision-export 看有正文但无历史的项目；两者均可下载，不产生新版本。

后端停止后，项目根目录运行 `python3.12 scripts/project.py export-demo`；默认 8008、独立 `data/export-demo/`，重启保留样例。前端独立副本使用 `BACKEND_API_URL=http://127.0.0.1:8008 npm --prefix /tmp/revision-export-frontend run dev -- --webpack --hostname 127.0.0.1 --port 3008`。副本被清理时由开发者准备，不要求产品经理建目录或改文件。主应用 http://127.0.0.1:3000 保留生产预览；本轮只查看主应用页面与数据可读性，没有下载私人项目文件入证据包。

## 已核对的结果

导出包含当前剧本／分镜和全部归档快照、来源、时间、恢复关系及差异／影响信息，保留数字与文字类型、空值、未知字段和完整结构。未归档正文独立标记；不导出内部请求幂等、会话元数据、配置、媒体、资产库、任务／计划或人工核对记录。本轮没有导入恢复，不是完整项目备份，不改变留存／删除规则。

两份文件由实际浏览器下载后保存，和真实 HTTP 原文件字节、摘要一致：JSON 15,445 字节，TXT 27,731 字节，均含八条历史。[JSON 人工下载样例](samples/text-versions-demo.json) 与 [TXT 人工下载样例](samples/text-versions-demo.txt) 可直接核对。实际代理会压缩并移除 Content-Length，已修正为校验原文件字节头、真实读取字节数及 SHA-256，并补充回归；压缩传输长度不会误作原文件长度。

实际浏览器验证了两格式下载、未保存草稿保留、断网安全提示及手动恢复、真实 409 依据过期提示、重复按钮阻断和工作区更新后迟到响应不下载。重新读取时取消放弃保持草稿，确认后正常重读。390／768／1280／1440 宽度无页面横向溢出，按钮可见可用；主应用最终生产构建的 1440／390 页面也已检查。上述宽度检查不代表实体手机验收。

独立真实 HTTP 服务重启前后，工作区、JSON、TXT 三份响应逐字节一致，八条历史及四个样例文件保持。原 195 个保护文件零改写、零缺失，主库五项目可读；导出不保存或创建任何业务记录，无模型、供应商请求、新增费用或素材外发。配置值静默扫描未发现密钥进入提交内容或前端产物；环境与用户数据仍排除在 Git 外。
