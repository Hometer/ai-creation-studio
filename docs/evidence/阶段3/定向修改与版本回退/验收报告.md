# 定向修改与版本回退验收报告

2026-10-05。按产品经理要求，先出开发文档，再开发、验证，最后本地提交。本轮交付本地文字修改与版本功能；整体阶段 3 的真实模型、完整业务和真机验收仍待验。

## 可以核对什么

在项目“素材与版本”页进入“文字修改与版本”。剧本和分镜都有独立的当前文字版本；选一处已有文字，修改前显示前后差异与影响，另行勾选后才保存。恢复旧版先预览该阶段的全部变化，再追加新版本，另一阶段、素材候选与视频选择保留。当前内容、历史、确认请求号在同一会话文件内原子保存。

版本从第一次本入口保存前开始；以前未记录的过程不能补出来。原编辑入口的更新会提示未归档，下一次本入口保存捕获当时内容。影响是保守的待核对记录，不代表下游已重做或已确认；不自动生成、发送、收费或继续流程。

## 打开地址与照着点

- [人工文字与七条版本](http://127.0.0.1:3003/projects/revision-demo/revisions)，独立数据，没有模型执行或收费接口。
- [空文字样例](http://127.0.0.1:3003/projects/revision-empty/revisions)，应明确显示没有可编辑文字，不能保存。
- [主应用素材入口](http://127.0.0.1:3000/projects/c78e11b1c484494e9faca397d8185a34/assets)，点“文字修改与版本”能进入已有人工项目的只读文字工作区；原五个项目保持。
- [主应用缺失项目状态](http://127.0.0.1:3000/projects/missing-project/revisions)，应显示找不到项目，可返回核对。

1. 打开人工文字页，点“分镜”，在“修改对象”选 `seg-1 · 镜头 1 · 镜头内容`，看到“守望者沿着木桥走向阿舟。”为当前文字算对。
2. 在“新内容”填自己的人工文本，点“预览修改与影响”。应该只出现这处前后差异和 `seg-1 · 镜头 1` 的核对提示；尚未勾选时“确认保存新版本”不能点。
3. 勾选核对后保存，应该出现一个新的版本；右侧旧版仍在，刷新能恢复这次历史选择。
4. 选 v2 分镜“首次归档”，展开相应正文，点“预览恢复这一版”。应该列出该阶段需要恢复的全部变化，并明确恢复的是 v2。勾选后保存会再追加一版；不会删掉刚才的版本或改变剧本。
5. 想检查剧本时选“剧本”与“章节正文 1”，填不同的新内容再预览。当前缺少可靠的章节到镜头映射，所以保守提示现有三个镜头都需核对。

这些操作只修改独立人工项目。记录数会随你继续保存增加；本轮交付时保留 v1—v7。需要重新启动人工服务，在项目根目录运行 `python3.12 scripts/project.py revision-demo`（8003）；前端启动与隔离构建方法在 README。“服务恢复”只读取保存内容，不自动重播任务。
