## 能自己核对的入口

人工演练地址：http://127.0.0.1:3017/projects/comparison-demo/co-creation 。这是隔离的人工接口样例，没有付费模型调用，页面和候选均明确标注来源。已保存第1份候选与关联文字第9版。

1. 打开地址，点第1轮请求，看到“已保存为文字版本”。
2. 在“已保存的候选任务”选择第1份，看到人工候选、单次5元／本轮20元、人工占用0.02元；实际账单仍未知。该占用仅属演练目录，不占用真实额度。
3. 点“查看关联文字版本”，核对新旧标题及镜头影响；返回共创页重新选候选，可继续查看历史。应用后不能再次确认或载入这份旧依据。
4. 新请求须先明确记录及确认意图，再准备候选计划，核对输入／费用及素材声明后确认生成。候选明确载入编辑框后，仍须预览差异和确认保存正式版本。

人工后端启动：根目录 `python3.12 scripts/project.py creation-candidate-demo`；隔离前端生产预览使用 `BACKEND_API_URL=http://127.0.0.1:8017 npm run build -- --webpack` 后在同一前端副本 `npm run start -- --hostname 127.0.0.1 --port 3017`。主应用新接口为 `/api/project/{project_id}/co-creation/candidates`；真实Key缺失时禁止确认执行。正常前端仍使用根目录原启动命令。
