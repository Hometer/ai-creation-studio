# 原编辑入口版本接线 · 验收报告

2026-10-05。按产品经理“先文档、开发、验证、提交”的规则交付本轮工程结果。原剧本／分镜页的结构与 JSON 手动编辑已接入本地版本保存；整个正式前端阶段、真实模型与业务验收仍未宣布完成。

## 自己打开检查

人工项目地址：[原分镜编辑页](http://127.0.0.1:3004/?session=manual-edit-demo&stage=storyboard)，[原剧本编辑页](http://127.0.0.1:3004/?session=manual-edit-demo&stage=script_generation)，[文字版本页](http://127.0.0.1:3004/projects/manual-edit-demo/revisions)。8004／3004 是独立人工演练，文字与引用均为人工样例，不代表模型结果。主工作室仍在 http://127.0.0.1:3000 。

1. 打开原分镜页，点底部“修改”。手机会显示镜头卡片，正文输入可直接操作。
2. 改一处正文，点“保存”。这里只预览；检查修改前后和受影响镜头。返回编辑可继续调整，确认区始终可见。
3. 勾选“我已核对修改范围”，点“确认保存新版本”。原正文自动归档；页面提示版本编号，刷新后还能读取。
4. 点“文字版本与恢复”，选择历史编号，点“预览恢复这一版”，确认覆盖的是本阶段完整正文，再勾选保存。恢复会追加新版本，旧记录及另一阶段保留。
5. JSON 编辑填入不完整内容时，保存应显示错误并保留输入；点取消或离开会提醒放弃草稿。失败或冲突时先复制需要保留的内容，再用“重新载入已保存正文”核对，不会自动重发。

演练目前十条版本：v1／v2 首次基线，v3 原分镜多字段保存，v4 原剧本修改，v5 JSON 新增镜头，v6 恢复 v2，v7／v9 是实际已提交后故意丢弃浏览器回复的验证，v8／v10 是第二客户端并发验证。当前分镜为“守望者与阿舟一起点亮渡口。”；两个失败验证草稿未覆盖当前正文。继续操作会正常增加人工版本。

## 已核对的结果

- 原页开始编辑从服务端同锁读取正文和修订依据；结构／JSON 保存只走本地文字版本，不走模型介入。未知根／章节／片段／镜头字段保留，根运行控制数据不能通过本轮编辑改写。无效 JSON 不会保存另一份结构草稿。
- 多字段与镜头增删进入全量差异，字段存在标记区分 null、新增和移除。保存前校验类型、深度、内容／历史大小与可读字段上限，不截断、不迁移。现有图片、视频、选中绑定、计划、预算、任务和阶段状态保持；影响只是待核对记录。
- 回复丢失：真实接口返回 201 后浏览器故意丢弃回复；每轮仅一次保存 POST、一个新增版本。页面保留草稿、冻结保存；主动读取恢复实际持久化正文。未用假接口冒充已保存结果。
- 浏览器网络断开后确认保存，未新增版本；草稿和错误保留。恢复网络并主动载入后显示已保存正文。第二客户端先提交，原页旧依据预览返回 409，保留草稿且不能覆盖；成功重新读取也同步原页展示。预览／保存等待期间锁定表单，避免核对途中改写草稿；实际延迟回复复验通过。
- 取消点击离开与浏览器返回均保留草稿。浏览器跨文档返回保护点已修复并复验；保存／取消后正常离开。手机原表格正文过窄已修复为卡片，390px 正文输入宽 327px、高 84px；删除按钮与输入有明确标签。
- 390／768／1280／1440 宽度检查覆盖剧本与分镜预览、结构恢复、断线及最终原分镜编辑。页面无无意横向溢出；长差异独立滚动，确认按钮留在可见区。生产主库空文字页与缺失项目、新增编辑读取代理复查；主库当前没有已完成剧本文字，没有新增模型结果充当演练。
- 最终后端全量 751/751（本轮新增 27），前端全量 224/224（新增 23），类型、零警告 Lint、生产构建通过。服务实际 HTTP 重启分别保留三、五、八及十条版本，工作区响应与会话文件字节一致。
- 主库五个原项目可读；原 160 个非日志业务／演练文件哈希无改写、无缺失。人工数据独立，未调用模型、未产生费用或外发素材。代码与生产产物扫描超过 1400 个文件，已配置秘密命中 0；Git 跟踪私密配置／业务数据 0。

测试命令与启动方式在 README。证据包不放命令输出和服务日志。
