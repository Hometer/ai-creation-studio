# 文字备份逐次确认与原子恢复 · 第 19 子阶段证据

2026-10-06。先行开发文档写完后开发，工程实现与离线检查已交付；真实模型、业务样例、手机真机及整体阶段继续待验。本轮只做本地提交，不推送。所有写入演练使用独立人工项目，没有调用模型、供应商、收费资源或对外发送素材。

## 产品经理照着验证

1. 打开 [独立文字版本页](http://127.0.0.1:3015/projects/comparison-demo/revisions#revision-import-precheck)，进入“检查文字备份”。页面保留 17 条人工版本、两条持久恢复记录。
2. 选择本目录的 [人工恢复前备份.json](人工恢复前备份.json)，点“检查这份备份”。看到来源 comparison-demo、10 条历史、17,939 字节算对。选择本身不上传，检查不保存正文。
3. 点“预览恢复当前文字”。看到剧本一处差异：左侧“人工下一次恢复演练标题”，右侧“人工恢复之前的新标题”；分镜零差异。恢复勾选默认关闭，保存按钮禁用算对。只看不保存时，点“取消恢复预览”。
4. 如要在这个人工项目试一次实际恢复，先复制需要保留的本页未保存文字，再勾选核对项并点“确认恢复并保存新版本”。已有编辑草稿或普通预览时会提示失效；取消保留原输入和两份预览。明确确认后才保存。若从上述保留状态首次操作，看到新增剧本 v18、第三条恢复记录、旧 17 条版本仍在算对；分镜不追加。后续再操作时编号随已有历史变化。
5. 展开“备份恢复记录 → 恢复依据”，可以核对文件大小、摘要、恢复编号和关联本地版本。刷新后文件需重新选择，恢复记录仍在；历史记录不代表那份文字仍是当前正文。
6. 保存断网、超时或回复丢失时，先点“读取恢复记录与版本”，不要直接再保存。找到记录表示已保存；未找到则需重新检查、预览、勾选后才能再发新请求。读取也失败时保持暂停写入，并保留原文件、输入及旧记录。没有自动重发恢复。

原文字版本页的查看／两版对比／逐次回退继续可用。仅恢复备份 current 的两阶段文字，有变化阶段追加本地版本；备份历史编号不会导入。原历史和恢复前未归档／空正文保留。媒体、共创、核对、计划和任务保留，旧依据需人工再核对，没有自动重制作。摘要保证内部一致，不能证明文件来源可信；当前仍是本机单用户边界。

空项目可打开 [独立空项目](http://127.0.0.1:3015/projects/revision-empty/revisions#revision-import-precheck)，选择 [人工空备份.json](人工空备份.json)，检查再预览应零差异、无恢复保存入口。选择另一个项目的文件只能检查来源范围，不能恢复。执行中限制用人工持久状态测试，没有真实后台任务。
