# 阶段 2 第 1 子阶段技术开发文档｜现有代码整合

日期：2026-10-04。本文在新增代码之前编写。配套：`技术适配声明.md`、`../PRD/PRD.md`。

## 一、阶段目标

交付可从根目录检查、启动和验证的小云雀工程，保留六阶段创作、临时工作台、文艺短视频、动作迁移、数字人口播和设置页。打通的片段为“创建项目 → 修改参数 → 保存 → 进程重启 → 恢复相同业务状态”。修复新项目被误判为已完成的状态。

本子阶段为工程整合，不实现整个 PRD；不进行收费生成、自动资产生成、3D、画布、账号、云部署或技术栈迁移。

## 二、技术适配摘要

延续现有栈、目录、API 前缀和文件存储。先交本文及适配声明，再改代码，验证后补交证据和状态记录，最后本地 Git 提交。接口错误增加 `error` 字段并保留安全 `detail`，避免已有前端依赖被打断。

## 三、技术栈与模型

Python 3.12、FastAPI、Pydantic、pytest；Next.js、React、TypeScript、ESLint、npm。根目录入口仅用 Python 标准库，不新增运行依赖。本次不选择或调用收费模型，现有适配器保留。

## 四、环境与配置

- 后端解释器为应用 `backend/.venv/bin/python`，拒绝误用系统 Python 3.9。
- Node.js 22、npm、Git、ffmpeg 用现有安装。
- `scripts/project.py doctor` 输出版本、依赖和端口可用情况，不输出秘密配置。
- `backend`／`frontend` 命令启动对应进程，绑定本机地址；不自动杀死占用端口的进程、不自动装依赖或调用模型。
- `check` 依次执行后端测试、前端类型检查、Lint 和构建；某项失败仍报告其他检查，最终退出码非零。

## 六、数据、资产与状态

- 会话 schema 1 新增版本号，保留原 `session_id/current_stage/status/artifacts/meta/stage_progress/error/created_at/updated_at` 字段；无版本号按 schema 0 读取。
- 磁盘 `updated_at` 继续用 Unix 秒；内存恢复成 datetime；状态响应继续提供 ISO 时间，避免重启前后类型变化。
- 启动和按需读取使用同一恢复函数。旧平铺生成参数仍恢复到 meta。人工 waiting 与已选 artifacts 原样恢复；运行中状态恢复不自动发起模型请求，不把“恢复数据”解释为“任务续跑已实现”。
- schema 或字段损坏时保留原文件、不覆盖、不在日志输出用户内容；未知未来 schema 不自动降级。
- 临时文件以 `.tmp` 后缀写入、flush/fsync 后 `os.replace`；失败清理本次临时文件，原保存仍可读；进程内采用原有 RLock，不支持多后端写同一数据目录。
- 项目创建和参数修改遇到保存失败时回滚对应内存变更，避免接口报错后仍显示未落盘的新参数。
- 会话 ID 仅允许受限字母、数字、点、下划线和连字符，拒绝路径穿越。
- 新项目六个业务阶段为 pending，init 不计入完成；只有六个业务阶段全部 completed 才显示项目已完成，错误和等待优先呈现。

## 七、API 契约

既有创建、模型参数修改、状态、历史会话接口保留请求和成功响应；本次不改 URL。

| 情况 | HTTP | 响应 |
| --- | --- | --- |
| 参数校验失败 | 422 | `{"error":{"code":"VALIDATION_ERROR","message":"请求参数不符合要求"},"detail":"请求参数不符合要求"}` |
| 未知资源 | 404 | `error.code=NOT_FOUND`，通用安全说明；保留 detail |
| 业务 HTTP 错误 | 原状态码 | 固定错误码与通用说明，不回显任意异常正文 |
| 未处理异常 | 500 | `error.code=INTERNAL_ERROR`，固定提示；日志仅记异常类别 |

兼容 detail 为临时措施，待集中式前端错误读取改造后移除需另行版本评估。原流式接口本次保留，SSE/NDJSON 协议整治列入下一生成链路阶段，不声称已合规。
