# 任务中心前端适配声明

日期：2026-10-05。先于本轮代码形成。产品经理已授权继续下一步，遵循先文档、再开发、验证后本地提交；模型继续后置。

## 理解与范围

面向独立短片／短剧创作者，把分散的项目流程、文艺短视频／动作迁移／数字人口播、临时工作台活动任务和本地持久化生成任务汇总到 `/tasks`。用户能看到状态、等待原因、结果与原工作台入口，按来源、状态、名称或编号查找。页面沿用“创作工作室”的深色与浅绿色设计，不恢复旧品牌展示。

本轮只读取已有任务。查看、刷新、筛选、打开详情和下载本地结果均不会提交、推进、重试、取消或删除生成任务，不出现尚无可靠合同的操作按钮。统一取消与付费重试留给后续执行合同；现有原工作台功能保留。没有模型调用、素材外发、云资源或新增依赖。

## 实际方案

保留 Next.js、React、TypeScript、Tailwind、Lucide 和现有 Node 测试工具。新增任务路由、独立任务组件、运行时校验／状态归一化模块，以及一个后端全库只读列表接口。现有项目、专项任务和沙盒接口保持兼容，新增接口仍使用统一错误结构。

项目与专项记录、本地生成记录读取各自既有磁盘存储，不新增第二套状态。临时工作台接口只有当前进程活动记录，页面明确提示其重启后不保证保留；本轮不把旧内存接口宣称为持久化历史。原业务数据不迁移。

## 状态与恢复

运行、排队、草稿、等待确认、完成、失败、需核对、未知状态分别呈现。项目流程只展示已完成阶段数；本地任务只展示后端阶段，后端映射出的固定百分比不是模型实际进度，不展示为生成百分比。专项接口有有效进度才显示其上报值。未知状态不推断成功。

四个来源独立读取；一个来源失败，其余仍可用，原快照保留并明确标注“读取失败，保留上次记录”。首次失败与空记录分开。请求有超时与取消，轮询不重叠，隐藏页面暂停；有活动任务时适度刷新，终态列表采用低频历史检查，失败退避。详情编号保留在 URL，刷新后从后端找回。

结果只允许本地受控资产媒体 URL，校验任务结果编号与 URL 一致；专项结果由原工作台继续管理。SIM 结果醒目标记“人工演练”，未知真实费用显示未确认，SIM 点数不转换为人民币。费用／平台原始错误、提示词、输入、文件路径不直接渲染。

## 验收与差异

保留现有 Node 自动化测试，不为本轮更换 Vitest 或框架；用真实浏览器补足交互、四种宽度、服务断开和恢复、视频播放／下载、实际服务重启等验证。文档和证据分别放在 `docs/阶段文档/`、`docs/evidence/阶段3/任务中心/`。

当前局部读取功能无新增业务决策。完整首版范围、真实预算、留存／备份、登录／上线仍记录为待定；本轮不扩大这些范围。真实模型与手机真机继续待验，本轮工程交付不代表正式阶段或整个项目完成。
