## 前端适配声明与范围

在共创页已保存草稿区增加按当前请求的逐份历史选择、时间和本请求保存次序。选择只显示该草稿全文，不替换编辑框；明确点“载入这份草稿到编辑框”才恢复人工文字。若本页有尚未保存且不同的新文字，先确认替换；取消保持输入和预览。载入清除旧预览／勾选，提示本页恢复与后端保存的区别；旧稿与最近保存内容不同即为未保存修改，离开保护沿用。

点“保存修改草稿”追加一份新草稿，原草稿均保留，不改正文或版本。正式应用仍需当前依据下重新预览、逐次确认和保存。刷新／返回默认恢复最近已存草稿，历史查看位置为本页临时状态，不冒充后端恢复结果；同页重新读取或出现新草稿时，已选历史记录保持，编辑框不得被静默替换。原“载入已保存草稿”继续恢复最近草稿。

沿用 Next.js／React／TypeScript、当前样式和原生带标签 select／details，无新增依赖、平台或费用。业务范围／预算／留存／账号台账保持待定；本轮仅工程交付，真实模型、业务、真机与整个阶段仍待验。无新模型、自动发送、备份导入、删除或跨项目草稿查找。

## 数据与接口契约

沿用 GET `/api/project/{project_id}/co-creation/drafts` → `{data,drafts}`、POST 同地址 `{expected_token,intent_id,value,request_id}` → `{draft_id,result}`。使用已严格校验的本项目草稿集合；按 intent_id 过滤，选择使用 draft_id，显示次序按本请求子集计算，不将项目全局编号冒充本请求次数。查看／载入完全本地，不发请求。

选择外来／不存在草稿不得回退为其他请求记录。恢复前确定性校验请求存在、依据对应、confirmed、未应用、非执行状态。未确认／撤回／已应用／旧依据只能浏览历史，不能载入为可写候选。保存中禁用选择与载入；冲突／结果不确定时保留当前输入和历史选择，暂停载入／保存，先读取核对。草稿字段、持久化账本及旧接口不变；旧无草稿项目显示原空状态。

错误沿用 error.code/message；404 缺失、409 变化／编号／执行状态、422 状态／结构／上限、503 存储不可用。原 20 秒超时、单次请求、无自动重发、请求编号读回和原子追加保护继续有效。
