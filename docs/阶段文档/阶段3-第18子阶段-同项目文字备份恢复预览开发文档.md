## 前端适配声明

在现有文字版本页和只读预检结果中增加明确的“预览恢复当前文字”。沿用 Next.js／React／TypeScript、深色变量、原生控件、差异前后两栏与折叠结构展示；复用现有文件校验、受限上传和差异／影响计算，无新依赖、平台、迁移或收费。前端手册全文已读，继续当前 Node 自动测试及 ego-browser 实际浏览器验收，不替换稳定工程。用户、视觉方向已定，范围／预算／留存／账号等待定事项保持台账，不影响本次本机只读范围；模型继续后置。

## 目标与范围

用户先选择 JSON 备份并明确检查，通过后仅同项目文件可明确请求恢复预览。预览以本项目当前正式正文为“当前”，以备份 current 中的剧本／分镜快照为“备份拟恢复文字”；两阶段一并展示全部结构差异，包含新增／删除、类型变化、附加字段和空值，不只比较可编辑字段。显示变化总数、各阶段字段数、可能受影响片段／镜头；内容相同时明确无需恢复。备份历史仅供范围核对，不导入历史，不把任何旧 token 当恢复许可。

本轮只读：没有应用／确认恢复／保存按钮，不改当前正文／历史／共创／媒体／任务／计划或费用，不生成写入授权，不调用模型。备份来源项目必须等于目标项目；不同来源仍可用上轮预检查看，后端拒绝恢复预览。项目执行中后端拒绝预览，界面说明等待任务结束；预检仍可只读查看。文件来源不因摘要校验可信，后续真正恢复要另行明确确认、原子追加并保留当前版本。

## 接口契约与确定性计算

POST `/api/project/{project_id}/content-revisions/import-preview?expected_token=当前项目摘要&filename=安全文件名.json`，请求为所选文件原始字节，Content-Type application/json，不压缩。复用预检的真实类型、安全文件名、64 MiB 流式限长、严格 v1 JSON／必填标签／摘要／编号／恢复关系／当前引用验证；深度 64、500000 节点、每快照 2 MiB、每阶段 500 字段、历史 32 MiB 不变。

返回严格只读结构：project_id、token、mode=read_only、source_project_id、file_bytes、file_sha256、scope=backup_current、total_changes、两阶段 stages（before_digest／after_digest、before_field_count／after_field_count、changes、impacts）。changes 沿用前后值／路径／存在性／类型／标签契约，impacts 沿用片段编号／镜头号／原因；当前与备份两份分镜的影响并集保守展示，不表示已重做或审核。两阶段合计最多 2000 差异，完整响应最多 8 MiB，当前快照也检查 2 MiB／字段上限；超限拒绝而不截断。比较依据从后端持久项目读取，锁内校验目标 token 与运行状态并计算，不信任前端传来的正文或预检结论。

前端再次核对原文件 SHA-256／大小、当前项目／token／来源及预检中的目标快照摘要／字段数；严格校验差异类型、存在性、重复路径、总数与影响，无差异必须无影响。20 秒超时、不自动重试；失败保留文件与本页编辑输入、清掉旧恢复预览，手动重试。后端校验来源、运行状态及 current token，错误统一 error.code/message，不输出文件内容或堆栈。

404 项目不存在；409 当前文字／历史变化或项目执行中；413 大小超限；415 类型／文件名不支持；422 文件／关系／来源项目／差异或响应容量不符；503 目标存储不可读。查询参数自身格式错误沿用安全校验响应。本机单用户服务边界不变，不冒充正式账号隔离。

## 风险与后续

备份可能来自不可信文件，SHA-256 仅保证内部一致与请求绑定，不保证来源；预览只比较快照，不导入原历史编号或请求关联。结构恢复可能使媒体／计划／共创依据过期，当前只明确列出保守影响，未执行恢复。下一轮可实现同项目文字备份逐次确认与原子恢复，需保留恢复前正文／原历史、按文件／预览／当前 token 绑定、两阶段同事务及回执找回；不提前接入本轮。完整项目备份、多用户、模型／费用／业务／真机和整个阶段仍待验，A07 保持开放。
