本轮测试延续 Node 内置测试与已安装的 TypeScript 编译器，增加数据转换／恢复、错误与状态回归；真实浏览器连本地真实后端检查布局与页面操作。生成效果仍待真实模型验收，不新增测试框架或收费调用。
