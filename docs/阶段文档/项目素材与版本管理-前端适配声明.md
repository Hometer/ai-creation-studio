# 项目素材与版本管理前端适配声明

2026-10-05，基线 fd97ff5。产品经理已授权上一轮提出的项目素材库、上传归档、版本管理及前后端联调，本声明与开发文档先于代码形成。

## 项目与本轮目标

面向独立短片／短剧创作者，沿用现有本机创作工作室。在项目中管理角色、场景、道具、图片和视频，查看历史版本，明确选择项目或镜头引用的版本。修改素材仅追加版本，不自动升级引用、不重新生成。

输入依据为初版 PRD F03／F06、现有资产与版本／媒体归档合同、前端手册全文及前两轮视觉方案。沿用已选深色界面、绿色强调色、系统中文字体和场记板标识；不恢复原产品的前端品牌展示。

## 技术选择

保留 Next.js 16.3、React 19、TypeScript strict、Tailwind 4、Lucide 与当前依赖锁文件。新增项目素材路由、业务组件和集中资产 API 适配层，复用 AppShell、BrandHeader、MediaImage。组件临时状态由 React 管理，查看位置通过 URL 保存，业务版本及引用以后端持久化结果为准。无新状态库、编辑器或依赖。

后端已有文字建档／追加版本、脚本及媒体产物归档、明确版本引用、使用位置与并发修订检查。媒体上传尚不能直接进入归档库，因此新增本地 multipart 上传归档接口，复用真实媒体验证与原子存储。新来源为 upload，记录项目及幂等编号；旧库、旧来源与 API 保持可读，不迁移会话数据。

## 状态与恢复

读取区分加载、空、失败和成功；保存显示提交中，防重复，不自动重试写请求。失败保留输入。上传使用幂等编号，响应失联后可用原编号重试；文字建档与追加沿用既有非幂等接口，失联先重新读取，不宣称保存失败或直接重复提交。引用更新携带 expected_revision，冲突时重新读取并再次确认。

页面可直接刷新，按项目、资产与版本编号重读真实数据。用户主动点击才创建引用或切换版本。这里没有模型任务、SSE 或自动生成。取消表单仅放弃未提交输入，不称作取消后端任务。

## 页面、产物与验收

首页项目卡与六阶段工作台提供“素材与版本”入口。素材页包含项目／全部素材、分类检索、卡片列表、预览与历史版本、文字编辑／本地上传、项目和分镜位置引用。图片与视频通过已有受控媒体 GET 读取，提供失败提示和下载；不公开归档目录。

检查 390、768、1280、1440 宽度，键盘、手机菜单和长文／长文件名。使用当前 Node 内置测试与真实浏览器验收，延续现有测试设施，不为本轮更换测试框架。最终运行全量后端／前端回归、类型／Lint／构建，并实际重启服务验证恢复，交付截图、步骤、闸门后本地提交。

## 边界与待验

模型继续后置，不收费、不外发素材、不新建云资源。本轮仍是本机单用户工程切片；账号隔离、留存期限、正式上线及完整 PRD 范围保持原台账待定，不扩大交付范围。真实模型效果按原决策标记待验。已有业务待定项不阻止本轮已授权的本地素材操作。
