## 接口与持久化契约

旧 import-precheck／import-preview 行为保持。新增 POST `/api/project/{id}/content-revisions/import-prepare`，原始 JSON 请求体和 expected_token／filename 与预览相同，返回 `{preview, confirmation_token}`；重新执行全部文件与当前目标检查，绑定项目、当前 token、原始文件 SHA-256／大小和完整差异。仅生成确定性确认依据，不写文件，不代表来源认证或模型授权。

POST `/api/project/{id}/content-revisions/import-restore` 同样发送原始 JSON 字节；query 为 expected_token、filename、confirmation_token（64 位摘要）、request_id（32 位十六进制）、acknowledged（必须为字面 true）。后端不信任客户端预检结论，重验文件、来源／运行状态／目标 token、重新计算差异与确认摘要后才保存。返回 `{receipt, data:{workspace, restores}}`；GET `/import-restores` 原子读取工作区和全部持久恢复记录，可按 request_id 查回不确定回执。重复同请求同内容只返回已有记录；编号被其他内容／操作占用返回 409。重读恢复记录不能自动重新 POST。

新的可选会话字段 backup_restores：schema_version=1、records（最多 100 条、256 KiB），记录恢复编号、请求编号／摘要、日期、文件摘要／大小、原目标 token、确认摘要、两阶段前后快照摘要、有变化阶段对应本地 version_id。不存文件名、原上传文件或重复快照。记录和追加版本必须严格关联，损坏拒绝读取／写入；旧无字段文件不写回迁移。复用现有进程锁、乐观正文／历史／账本校验、fsync＋临时文件原子替换；任一失败回滚内存，持久正文／历史／恢复记录只可能一起成功。原每快照 2 MiB、500 字段、历史 32 MiB，文件 64 MiB、两阶段差异 2000／完整预览 8 MiB 均保持；超限拒绝，不删除历史。

错误统一 error.code/message，不泄露完整文件或堆栈。404 项目不存在；409 执行中／旧依据／确认摘要不符／请求编号复用；413 文件超限；415 格式／文件名；422 文件结构／关系／来源／容量／零差异／未明确确认；503 存储或保存未确认。只支持原本机单用户边界，不冒充上线隔离。

## 页面状态与编辑保护

| 状态 | 行为 |
| --- | --- |
| 尚未检查／不同来源／运行中 | 不能恢复，沿用检查范围查看 |
| 恢复预览有变化 | 展示完整差异、影响与保留旧版本说明；勾选默认关闭，按钮禁用 |
| 勾选后明确恢复 | 先确认当前页草稿／原预览会失效；取消保留原状态，确认后才发一次写请求 |
| 保存中 | 文件、检查／预览／恢复、普通编辑／保存／重读及导航锁定；离开提醒 |
| 成功 | 显示持久恢复编号和新增版本，更新正式工作区，清理旧编辑预览与勾选；已存历史保留 |
| 断网／超时／不确定结果 | 保留文件与输入，清旧恢复确认，暂停写入；提示“读取恢复记录与版本”核对 request_id，不自动重发 |
| 已查到记录 | 显示已保存及版本，即使随后又有修改也不假装该恢复仍是当前 |
| 未查到记录 | 说明本次未找到持久记录，需重新检查／预览／确认后发新请求 |
| 换文件／重检查／重读／刷新 | 清旧预览和勾选，刷新文件不恢复；持久恢复记录可重新读取 |

读取记录失败保留旧数据并明确不可写；换文件也不能绕过不确定回执保护。保存结果严格绑定请求编号／文件／确认依据，迟到报告忽略。20 秒超时、无自动重试；请求只在明确动作时发送。正文更新由父页面统一接入；检查／预览仍不改变本页编辑草稿，实际恢复前明确提示草稿失效。
