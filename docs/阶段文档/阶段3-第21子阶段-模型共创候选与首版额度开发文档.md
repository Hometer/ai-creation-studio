# 第21子阶段｜模型共创候选与首版额度

日期：2026-10-06。先形成本文再编码。承接第一版 F02，复用已确认共创请求、文字差异、人工保存和版本关联；补齐实际模型候选入口。用户已授权完成F01—F08并批准单次5元、本轮20元上限，授权不包含未经核对的素材外发或云资源。

## 前端适配声明

沿用Next.js／React／TypeScript strict、既有深色界面、原生控件及Node测试。共创页新增候选生成区，复用人工修改编辑框；模型候选明确载入后仍需差异预览及逐次确认保存。候选生成不直接修改正文、媒体或选用版本。原手动修改和草稿功能保留。

## 范围与流程

1. 用户围绕一处剧本／分镜文字记录并确认修改意图。
2. 读取模型候选工作区，显示后端Key可用性、模型、价格依据、本轮已占用和剩余额度。
3. 明确准备候选计划：固定对象、原文、用户原话、保留要求及必要项目文字上下文，展示保守费用估算和输入范围。准备保存候选计划，不修改正文、不调用模型。
4. 用户核对估算和有权非敏感素材境内处理声明，明确确认生成。任务、输入和额度先持久化再调用；一次请求最多提交一次。
5. 成功候选保留新文字、修改说明和保留要素说明；服务端校验结构、长度及变化，不接受模型提供的文件路径或执行指令。
6. 明确载入候选到原编辑框，保留原正文，再走已有预览／确认／关联版本保存。取消载入保留未保存输入。
7. 刷新、回复丢失或重启后通过任务编号找回；提交已开始但结果未知时提示人工核对，不自动再次收费。

## 接口与状态

新增共创候选工作区、准备计划、确认入队、任务状态和推进接口。请求使用严格项目／任务／意图标识、当前依据摘要、计划摘要、独立请求编号及显式确认。错误统一error.code/message，503不泄露SDK或私有内容。旧共创合同保持兼容，候选执行权限由新增接口单独返回，不复用旧model_enabled=false作为发送许可。

任务状态：待确认计划、queued、submitting、succeeded、failed、manual_review。计划过期、正文／请求变化、运行中、无Key、价格失效、费用超单次／累计上限均阻止提交。HTTP写回复不确定时先重新读取，无自动POST重试。

模型适配采用境内百炼文本接口，优先固定qwen-plus-2025-12-01非思考JSON输出，单候选max_tokens=4096，单次发送，无隐式付费重试。复用既有HTTPS校验、公共DNS限制、响应大小、总截止与日志脱敏能力；SDK／配置初始化失败不发送。价格参考2026-10-06[官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)，参数依据[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。价格以有有效期的后端依据管理，不把免费额度当零费用；准备时以完整请求字节保守估算输入规模，限制到已核对价格阶梯；实际token消耗与估算分别保留，账单金额未知仍显示未知。

## 数据与费用

候选计划、任务及本轮人民币额度在独立本地业务账本原子保存，与原会话共享明确锁顺序及依据检查；不改旧会话结构。全项目共享单次500分／本轮2000分限制，不提供浏览器重置额度入口。任务确认原子占用，结果未知保留占用；重复确认幂等。账本损坏拒绝覆盖，容量超限明确拒绝，不截断。用户文本可作为必要持久业务数据，日志／URL不记录正文、Key或完整输入。
