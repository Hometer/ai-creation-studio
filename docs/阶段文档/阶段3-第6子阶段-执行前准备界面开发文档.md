# 阶段 3 第 6 子阶段：执行前准备界面

2026-10-05。产品经理授权继续，按先文档、开发、验证、证据交付、本地提交执行。依据 PRD F07／F08、项目状态及既有报价预算审核／执行前检查合同。本文先于代码形成。

## 前端适配声明

沿用已确认的创作工作室视觉、Next 16／React 19／TypeScript strict、同源转发、系统中文字体与 Lucide。不增加依赖、平台或费用。新增 `/projects/[projectId]/plans/[planId]/preparation`，从计划详情进入。本轮业务闭环是人工价格依据 → 本地额度 → 逐计划素材声明 → 固定估算 → 明确保存本地准备 → 手动检查／取消 → 刷新和重启恢复。

真实模型继续后置；本地准备、检查或勾选声明均不能签发发送／扣费许可。不创建生成任务、不调用平台、不预留真实资金。预算、登录、首版范围及留存业务决策沿用状态台账待定，不影响本次本地闭环，不重复提问。

## 范围与默认值

- 价格依据沿用后端已适配的两个万相模型名称、720P／1080P 的整数分每秒及有效期。界面明确“人工填写，账户价格未核验”；不声称当前官方能力或真实报价。未知报价显示待确认，不能显示零元。参考图模式及其他模型／规格可看历史和阻断原因，不静默改计划。
- 价格和额度是本机工作室共享设置，更新会影响其他计划。各有明确核对勾选；保存新版本保留旧记录。额度表单说明单次 ≤ 每日 ≤ 每月，已分配量不允许被新上限压低。金额用十进制字符串转换为整数分，避免浮点和科学计数法。
- 素材审核三项默认不勾选，可保存否认声明，后台记录 accepted=false；审核针对计划摘要。保存成功后清空勾选，不自动重用旧授权。
- 估算点击才保存，不在打开／刷新时 POST。报价有效期最多 20 分钟，以后台结果为准；准备绑定报价摘要、当前审核和预算版本。勾选明确“仅保存本地准备”后提交，生成请求编号防重。
- 历史准备可选中，URL 的 preparation 参数支持刷新与历史恢复；显示保存时金额、当前本地占用、有效性、阻断及检查历史。取消需再次确认，沿用 expected_revision，失效或过期的准备仍可取消释放本地分配。取消后不得复活，需新估算。
- 已分配但失效的准备仍占用本地额度，明确引导取消；不自动释放。当前／历史检查区分，检查通过也显示真实执行关闭。

## 页面状态与恢复

初始加载、无设置、无估算、无准备、待声明、未确认计划、条件不满足、准备可核对、失效、已取消、历史不存在、项目缺失、读取失败、提交不确定分别显示。读取失败保留上次数据供查看，暂停写入；重新读取成功后才开放。项目缺失时历史只读，但允许明确取消已有本地分配，避免额度被永久占用。

所有写操作同步锁防连点，读取与提交不自动重试。超时、断线、5xx 或成功响应合同异常均视为结果不确定，保留输入且暂停提交，要求重读历史核对。重读失败不恢复写入。报价／审核／设置无旧幂等接口，不自动重发；准备沿用后端 request_id 幂等。未保存编辑和忙碌时有离开提示，刷新丢弃临时表单但后端历史保留。跨标签没有编辑锁，保存后核对实际服务端结果；服务端重新验证准备条件，不以前端按钮作为安全边界。

## 接口契约

| 请求 | 请求体与返回 | 边界 |
| --- | --- | --- |
| GET /api/generation-plans/{plan_id}/readiness | 新增只读 ReadinessWorkspace：plan、project_exists、current_price、budget、reviews、quotes、preparations、checks | 在资产事务锁内一致读取；404／503 统一 error.code/message；不写文件、不联网，校验计划所属项目 |
| POST /api/wan-prices | PriceInput → PriceView | 人工来源、整数分／秒和到期时间；账户未核验 |
| POST /api/wan-budget-policies | BudgetInput → BudgetPolicy | manual_setting、preparation_only=true，所有项目共享 |
| POST /api/generation-plans/{id}/sample-reviews | ReviewInput → ReviewView | 当前摘要、三项布尔声明、preparation_only=true |
| POST /api/wan-quotes | plan_id → QuoteView | 估算绑定计划和价格版本；不可估算返回 null 与原因 |
| POST /api/wan-preparations | quote_id/hash、review_id、budget_id、request_id、preparation_only=true → PreparationView | 后端再次检查有效期、当前版本、输入协议、声明和额度 |
| POST /api/wan-preparations/{id}/cancel | expected_revision → PreparationView | 取消本地准备，历史保留；非撤销真实任务 |
| POST /api/wan-preparations/{id}/execution-check | 空对象 → ExecutionCheckView | 只编译检查，不发送，network_used=false |

GET 20 秒、POST 60 秒超时；400／404／409／422 安全提示，500／不确定写入要求重读。集中 API 层严格校验金额、关联、布尔边界、未知值、空值和历史状态，不把实际费用未知显示为已支付零元。响应不展示私有媒体路径、编译请求或 Key，检查仅摘要／分类。现有存储和接口兼容，无迁移。

## 风险与回退

共享设置替换会使其他准备失效，但不自动退还本地分配；页面明确范围及取消入口。历史报价会自然到期，查看结果以最新读取为准，过期时重新估算。长期历史聚合尚未分页，当前适用本地小规模；多人权限和跨标签编辑锁不在本轮。仅移除新增入口可回退界面，后端已有历史与接口保留，不删除数据。
