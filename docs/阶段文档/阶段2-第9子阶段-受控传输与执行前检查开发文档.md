# 阶段 2 · 第 9 子阶段：受控传输与执行前检查

日期：2026-10-05。本文先于本轮代码形成，沿用不收费调用、万相准备目标、有权非敏感素材境内处理三个已定决策。

## 本轮结果与范围

实现默认拒绝联网的 HTTP 传输组件，并增加准备记录的本地执行前检查。检查重新核对计划确认、固定版本素材字节、报价有效期、当前价格／预算／样例审核和上海日月期间。合格输入仅在内存编译，保存请求摘要，随后释放；检查结果不是调用许可。

保留现有资产、计划、SIM 任务、离线协议演练及报价准备接口。没有真实生成、平台认证、收费、对外上传、真实资金预留／结算、后台 worker、新增正式前端或云资源。不存在启用联网的 HTTP 参数、环境开关或 Key 自动启用逻辑。真正运行传输之前仍需后续确定性授权和真实账本接线；本轮不提供授权签发器。

## 传输设计

独立 `core/wan_http_transport.py`，复用现有协议 `Reply`、路径／大小上限与错误类型，不改变仅接收 offline transport 的 `WanAdapter`。生产组件的初始化始终返回 REAL_EXECUTION_DISABLED；所有传输入口先检查该边界。已编写的底层 HTTP 行为由测试专用子类连接 127.0.0.1 人工服务器核验，生产组件没有可配置的本地 URL 或绕过入口。

底层仅允许 POST 视频提交路径和 GET 合法任务 ID 路径，提交不重试，查询／下载本身也不自动重试，次数由未来持久化任务管理。API 地址限北京 HTTPS 官方地址；无代理、Cookie、重定向或任意传入请求头。Bearer 只用于 API，下载不携带 Key。结果域名沿用上海 OSS 精确白名单，不把签名 URL 放入日志或持久化。

DNS 解析有等待上限，所有解析地址必须为公网；TLS 连接固定选定地址并保留官方域名 SNI／证书校验，避免检查后再次解析。连接／读取上限 5／20 秒，总时限不超过 30 秒；流式读取限制 JSON 256 KiB、视频 100 MiB，拒绝异常长度、截断、重定向和非 200。绝对截止时间中断慢流。初始化、网络及响应错误均转为固定错误码，不输出远端正文、完整 URL、Key 或请求内容。DNS、TLS、真实认证与境内处理效果未通过平台实测，仍待验。

## 检查与持久化

新增 `execution-checks.json` schema 1，保存在现有私有资产目录。复用计划／资产／准备的共享进程锁与文件锁；在同一事务读取最新准备条件、编译摘要并原子保存，fsync 后才返回。GET 不写文件，不重新编译请求，不触发网络。损坏、重复字段、未知版本、缺失字段或符号链接返回安全 503，保留原数据。

记录包括检查 ID、准备 ID、创建时间、准备修订、计划／报价／审核／预算与期间摘要、连接脱敏分类、每个片段请求 SHA256 和固定问题码。无完整提示词、Base64、归档路径、Key、签名结果 URL。恒定 preparation_only=true、real_execution_allowed=false、submit_attempts=0、provider_task_id=null、real_money_reserved=false、actual_charged_minor=null。

输入编译只有当前本地准备条件通过时执行；每份请求在归档重新验 SHA 后生成摘要。任一输入失败均标记检查不通过，不以部分摘要冒充完整准备。历史 GET 比较当前准备修订、有效期、价格／审核／预算／计划和期间、连接分类以及现时素材检查，显示 current；current 只表示本地条件仍吻合，永远不是发送许可。Key 的内容变化无法从存在性分类辨识，不声称凭据已认证。未来发送必须再次原子核对、建立真正费用预留和持久化提交检查点，不能消费历史报告作为授权。

## 接口契约

| 接口 | 请求 | 返回 | 错误 |
| --- | --- | --- | --- |
| POST /api/wan-preparations/{id}/execution-check | 严格空对象 `{}`，禁止执行开关或额外字段 | 201，持久化检查及 current，输入是否编译成功、条件问题及真实执行阻断项 | 404 不存在；422 请求非法；503 存储不可用 |
| GET /api/wan-execution-checks/{id} | 无 body，32 位十六进制 ID | 200，历史检查与 current；不改费用或任务 | 同上 |

条件不通过依然保存报告并返回 201，以便复核；不是任务成功。统一错误保持 `{"error":{"code":"…","message":"…"},"detail":"兼容信息"}`，不包含堆栈。真实执行阻断包含 REAL_EXECUTION_DISABLED、REAL_TRANSPORT_UNAVAILABLE（组件尚未绑定执行器）、AUTHENTICATION_UNVERIFIED、REAL_BILLING_UNCONNECTED，并保留 fixture／Key／地域阻断。
