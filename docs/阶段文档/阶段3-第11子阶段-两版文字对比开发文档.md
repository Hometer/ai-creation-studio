# 两版文字对比开发文档

日期：2026-10-05。先形成本文，再开发。阶段 3 第 11 子阶段工程切片，真实模型／真机／业务验收继续待验。

## 目标与默认范围

在现有文字版本页选择同一项目、同一阶段的任意两个归档版本，查看左右差异、字段增删、结构及类型变化和待核对镜头。可以交换方向、刷新恢复选择；同一版本或内容相同的不同版本明确显示无差异。沿用现有风格，桌面左右并排，移动端顺序阅读。

默认采用字段／结构级对比，理由是可完整呈现现有快照，并能区分章节或镜头增删；不将差异条数当修改字数。不新增逐字高亮、未归档草稿对比、导出、自动恢复、模型或制作执行。比较本身只读、不归档、不改变当前文字、人工结论、媒体、计划或预算。已有编辑草稿和恢复流程保留。

## 接口与一致性

- GET `/api/project/{project_id}/content-revisions/compare`。查询参数为 `expected_token`（当前工作区摘要）、`before_version_id`、`after_version_id`（各 32 位版本 ID）。版本只从当前项目历史查找；跨阶段返回 422，找不到返回 404，工作区变化返回 409，存储损坏返回安全错误，错误统一含 `error.code/message`。
- 响应含项目、阶段、摘要、左右版本 ID、差异及保守镜头影响。差异保留路径、字段名称、左右原值、存在标记和类型，区分缺失／空值、数字／文字等情况，不能仅凭渲染文字相同省略真实变化。
- 同一引擎锁内读取并校验历史；不调用保存方法。沿用单版 2 MiB、500 可编辑字段限制；新响应最多 2000 条差异／8 MiB，超限明确拒绝，不截断，不修改已有数据。
- 分镜对比检查两份快照的前后镜头；剧本对比以读取时当前分镜提示待核对范围。比较提示不是历史制作完成证明或执行批准。

## 前端体验与保护

版本页新增独立对比区，阶段筛选、两个版本选择框、交换方向和“查看两版差异”。版本编号／来源清楚，版本不足、无差异、读取中、断网、冲突、坏响应均明确显示。结果必须绑定所选方向和工作区，旧请求不能覆盖新选择。

选择写入地址查询参数，刷新或返回可恢复；非法、失踪或跨阶段选择提示后允许重新选择，不静默替换成别的版本。比较不修改编辑器、草稿或现有恢复确认；错误提示就在对比区，重新读取版本时沿用原草稿保护。

接线检查发现旧历史摘要只保存渲染文字，例如字符串 `1` 与数字 `1` 可能显示相同。版本读取不能据此拒绝真实类型变化：仅允许可解释为非文字 JSON 值的此类摘要，仍拒绝普通文字的伪变化；手动预览继续核对实际输入。新对比从完整快照恢复类型并严格校验，不迁移旧历史。
