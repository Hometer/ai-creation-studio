# 对话共创记录与修改意图确认开发文档

2026-10-05，阶段 3 第 13 子阶段。本文先于代码形成。依据 PRD F02 和上一轮“优先对话共创”安排，交付项目内修改请求、明确对象／保留要求、人工确认与历史恢复的本地闭环；模型继续后置，不新增费用或外发。

## 前端适配声明

沿用现有 Next.js／React／TypeScript strict、Lucide、语义 CSS、FastAPI 和本地单用户单写引擎，不升级版本或增加依赖。新增 `/projects/{id}/co-creation`，从素材页及文字版本页进入。桌面分为请求表单与历史区，小屏纵向；沿用“创作工作室”的色彩、字形、导航和卡片。请求集中在 lib，普通 HTTP，不引入 SSE、轮询或模拟 Agent 回复。确定性范围卡与模型回复明确区分。

已读项目状态、PRD 对话共创需求、当前阶段前端手册及现有版本／持久化接口。真实模型效果、成本、登录与正式交付沿用待定台账；本轮没有改变这些事项。默认每次选一个现有剧本或分镜文字字段，原因是已有版本功能能准确定位，避免自然语言自动扩范围。无字段的空项目显示先准备正文，不伪造可修改内容。

## 范围与流程

用户选剧本／分镜的一处字段，输入修改意图（最多 10,000 字）和必须保留的内容（最多 2,000 字，可空），点“记录修改请求”。后端保存原话、对象路径／名称／当前文字、完整文字版本依据和时间。页面展示本人请求及“范围核对”卡，写清只有该对象进入后续修改、其他文字需保留；影响仍需后续真实修改预览，不声称已经理解或生成正文。

勾选已核对对象与保留要求，点“确认修改意图”追加持久化确认；也可“撤回这条请求”，追加记录、原请求不删除。已确认后仍可撤回。正文或历史变化后，旧待确认／已确认意图保守标为依据已变化，禁止再确认，允许撤回或创建新请求。确认只表明方向，不是执行、费用或外发许可；引导到已有文字修改／版本页继续人工修改。本轮不实现自动改写、意图到补丁的模型解析、自动应用、媒体重制作、导出对话、删除或多用户协作。

多轮请求按项目连续留存，可选择历史卡并用地址 `?intent=...` 恢复。未提交输入只在当前页，切换对象、重读／离开前提醒；读取失败、保存回复不确定均保留输入，暂停写入，先重新读取真实记录核对。若原请求已保存，通过 request_id 找回后清除对应草稿；明确未发现时才允许手动提交新请求，不自动重发。重读成功前不清空输入。切换项目／卸载后旧响应不覆盖新页面。

## 状态矩阵

| 状态 | 展示与动作 |
| --- | --- |
| 初始／加载 | 正在读取项目内请求与可修改文字，不提前显示空历史 |
| 空历史 | 说明尚无请求；有字段可记录，无正文指向原项目 |
| 未保存输入 | 显示字数与退出提醒；不当作已持久化请求 |
| 待确认 | 明确对象、当前文字、意图、保留要求；勾选后确认 |
| 已确认／已撤回 | 展示真实记录与时间；确认不代表已改写 |
| 依据变化 | 提示重新核对并建立新请求，旧记录保留 |
| 项目执行中 | 可读历史，暂停创建／确认；撤回本地意图不取消任务 |
| 故障／回复不确定 | 安全提示、保留输入；暂停写入，人工重新读取 |

## 接口与持久化

- GET `/api/project/{project_id}/co-creation` 返回项目 ID、工作区 token、text_token、running、两阶段可选 fields、请求 records 和 decisions；`model_enabled` 固定 false。只读，不创建空记录。
- POST 同路径：`expected_token`、`request_id`（32 位）、`stage`、`path`（现有字段）、`message`、`preserve`。成功 201，返回 `intent_id` 与完整 workspace，初始 pending。不接受正文 replacement、模型供应商、外链或自动执行参数。
- POST `/api/project/{project_id}/co-creation/decision`：`expected_token`、`request_id`、`intent_id`、`decision=confirm|withdraw`、`acknowledged=true`。成功 201 返回 intent_id 与 workspace。确认要求当前依据、字段存在、未撤回／未重复确认且项目未执行；撤回可用于旧依据或执行中的意图，但不取消任何任务。
- 错误统一 `error.code/message`，404 项目／请求不存在，409 依据／记录变化、执行中或请求 ID 复用，422 输入／状态／长度／数量上限，503 存储损坏／外部改写／保存未确认；不回显输入、私有路径、堆栈。前端固定安全文案，20 秒，无自动重试。
- 会话可选新增 `co_creation` schema_version=1，不改变旧会话版本；保留原字段，旧项目无记录正常读取。所有旧写入／加载路径保存该账本。读盘校验结构、顺序、身份、关联和大小，损坏时拒绝，不自动覆盖。
- 引擎锁内读取正文与账本、计算依据、校验幂等及追加，采用既有 atomic_write_session；异常回滚内存。相同 request_id／内容重复返回原结果，复用不同内容拒绝。最多 100 条请求、200 条决策、账本 2 MiB，达到上限明确拒绝、不截断、不删除。
- 请求／确认进入业务数据，不进入日志、URL 或配置；仅 ID 放地址。引擎缓存与磁盘不一致拒绝写入。本轮仍为本机单用户，正式上线账号隔离待后续，不以隐藏按钮代替授权。
