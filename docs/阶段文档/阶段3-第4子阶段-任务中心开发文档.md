# 阶段 3 第 4 子阶段：任务中心

日期：2026-10-05。本文先于代码形成，依据 PRD F08、现有任务合同与上一轮素材管理交付。

## 1. 目标与范围

在一个入口查看创作进展，找回需确认或失败的记录，查看本地已归档结果，再返回原项目处理。包含 `/tasks`、侧栏入口、状态统计、来源与状态筛选、搜索、详情、本地视频预览／下载和项目素材链接。名称统一为创作工作室。

不新增生成、付费确认、后台执行器、自动任务推进、统一取消／重试、删除、账号或部署。原工作台中的已有能力保留，本页面跳转本身不执行阶段。

## 2. 用户流程

1. 从侧栏“任务中心”进入，先看到读取状态，读取完成后显示记录和统计。
2. 按状态／来源和名称／编号筛选；无匹配时可清除筛选。
3. 点记录打开详情，显示来源、状态、更新时间、阶段与下一步提示；URL 保存选择，刷新后恢复。
4. 本地成功任务可预览、下载归档 MP4，SIM 明确为人工演练。其他结果回原工作台查看。
5. 断网时看见读取失败与保留的旧快照，恢复服务后手动刷新；不会重复提交任务。

## 4. API 合同

| 请求 | 响应／用途 | 错误与边界 |
| --- | --- | --- |
| GET /api/sessions | sessions 数组，项目名称／时间／阶段状态 | 运行时校验，损坏来源提示读取失败 |
| GET /api/tasks?limit=500 | tasks 数组，现有专项任务历史 | 当前接口最多最近 500 条，达到上限明确提示；不宣称全量 |
| GET /api/sandbox/tasks | tasks 数组，仅活动任务 | 原内存来源，终态历史不补造，明确恢复限制 |
| **新增 GET /api/generation-tasks** | TaskView 数组，全库持久化记录，按创建时间和编号倒序；包含已无项目的历史 | 无请求正文；空库 []；503 统一 error.code/message，保留损坏原文件；无保存、推进或平台查询 |
| GET /api/assets/{asset}/versions/{version}/media | 已有受控 MP4 预览／下载 | 仅 TaskView.result 的一致 URL；媒体失败独立反馈 |

新增 Next 同源 generation-tasks 转发。每来源请求设 10 秒超时；页面离开取消。四路并发，部分失败不清空其他来源。手动刷新只读；后台请求不重叠，隐藏页面暂停，活动任务 5 秒、纯历史 30 秒，失败逐次退避至 60 秒。页面返回时刷新一次。

## 5. 数据与状态方案

新增 `lib/taskCenter.ts` 做解析、状态映射、筛选／排序、受控 URL 和四路读取；`components/TaskCenter.tsx` 负责列表与详情，`app/tasks/` 放路由和样式。后端在原 GenerationTasks 锁事务中新增 list_all，不改存储 schema。临时工作台记录不另行落盘、不承诺恢复；已有重要记录仍由原持久化服务提供。

项目流程一条记录表示该项目整体工作流，展示完成阶段数，原待开始项目为草稿。来源编号加前缀避免跨来源冲突；未知阶段与状态显示未知，不自动升级。任务显示名称只取明确名称字段或通用标题，不把完整 prompt／input／error／路径当标题。模拟任务显示 SIM 范围与阶段，不把演练结果称为真实生成。

四宽度 390／768／1280／1440；桌面列表与详情并列，小屏垂直布局，选择后定位详情并可回列表，控件至少 44px。键盘能操作筛选和记录，状态反馈使用 live region；复用已有侧栏焦点管理与移动遮罩。

## 7. 风险与回退

旧来源未提供统一重启后 worker 执行合同，因此只呈现保存状态和来源说明，不自动恢复执行。终态任务媒体可能已被外部移除，须显示读取失败并保留任务。专项最近 500 条和沙盒仅活动记录的限制在页内说明。多人隔离待后续授权，不作为当前本机验收。

回退仅移除新页面／入口／只读接口，原存储与旧功能无需迁移。真实模型、付费、真机及整体业务验收继续待验。检查结果在交付后补入证据、README 和项目状态，再本地提交，不推送。
