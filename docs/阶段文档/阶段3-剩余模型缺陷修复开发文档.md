# 阶段 3｜剩余模型缺陷修复开发文档

- 日期：2026-10-05
- 基线：1ba6919；开工时工作区干净。
- 授权：产品经理确认先文档、后开发、验证后本地提交。本轮只执行剩余缺陷修复，不提前做生成计划界面。

## 一、目标与技术适配

关闭全面检查中的 A14 日志隐私、A15 空响应重试失控、A16 图片 TLS 降级三个确认缺陷；复核 A07 开发依赖是否存在兼容补丁。延续 Python 3.12、FastAPI、现有同步厂商客户端和 Next.js，不迁移数据库、不替换技术栈、不新增依赖或收费资源。模型后置、不联网调用模型、不上传用户素材。

现有首页、任务中心与素材界面保持原交互；本轮前端只运行回归、构建与代表页面检查。预算、首版范围、账号和留存等原业务决策不影响这轮离线修复，沿用状态台账，不重复提问。

## 二、先于代码确定的修复方案

| 编号 | 修复内容 | 可验证的结果 |
| --- | --- | --- |
| A14 | GPT/Gemini 文本及视觉客户端不记录消息、响应或上游异常原文；四类统一客户端的 PRINT_MODEL_INPUT 改为长度与数量摘要；参考图代理不记录提示词、媒体地址、模型反馈或业务名称；相关图片／视频厂商日志改为安全事件、错误类别或状态码；全部独立模型脚本移除 Key 片段与配置 URL、错误原文打印 | 即使开启输入摘要与 DEBUG，人工敏感标记也不出现在应用日志；诊断仍保留次数、错误类别和状态码。第三方 SDK 请求日志另加受控脱敏 |
| A15 | 四个 OpenAI 兼容客户端复用有限重试工具；每次请求（含空 choices、None、空白、错误响应结构）都计入 max_attempts；关闭 SDK 隐式重试；每次超时不超过剩余预算，退避不越过调度截止，不接受截止后返回的结果；构造失败转安全异常 | 成功返回非空字符串；上限耗尽或截止后安全失败；无请求在截止后启动；不把上游错误内容写入异常消息 |
| A16 | 移除 verify=False 和关闭 TLS 警告的代码；证书错误立即明确失败；其他暂时性下载错误有限重试。响应必关闭，临时文件原子替换，失败保留已有文件 | 每一次请求都验证证书；证书失败无降级调用；流读取失败不留下半成品或覆盖旧结果 |
| A07 | npm audit、注册表版本与上游公告复核兼容补丁；只在可兼容且回归通过时更新 | 无兼容补丁时如实保持开放，不强制降级或隐藏告警 |

SDK 依据为 [OpenAI Python 官方文档](https://developers.openai.com/api/reference/python)，并核对本地已安装 SDK 的 with_options、timeout、max_retries 参数。默认请求超时沿用 GPT 文本 300 秒、GPT 视觉 60 秒；Gemini 补显式 300 秒；总调度预算默认等于单请求超时，可通过构造参数 total_timeout 覆盖。总截止限制后续请求、退避与结果接受；底层 HTTP 超时按连接／读取阶段生效，不能承诺强制中断持续有字节返回的连接或第三方阻塞代码。真实网络延迟和计费行为仍待验。

## 三、接口、Prompt 与持久化

保留 query/chat 的输入参数、模型选择及非空文本返回；新增可选构造参数放在现有参数之后，原调用兼容。内部失败抛出固定消息的 ModelRequestError，现有 API 错误保护继续返回 `{"error":{"code","message"}}`，工作流 SSE 以 done/error 收尾。不新增生成入口，不变更 Prompt、模型名称、资产格式或费用授权。

重试工具只管理一次客户端请求，不承担任务执行恢复。任务、确认点仍由原持久化服务保存；已有后台线程自动续跑、多人隔离和真实费用闸门继续保持原待验边界。

## 四、测试与交付

1. 人工 SDK 覆盖四客户端的空 choices、None、空白、非法类型、异常、成功、混合失败后恢复；断言真实调用次数、无末次睡眠、SDK 重试关闭、超时缩短、截止停止和迟到结果拒绝。
2. 人工初始化失败、开启 DEBUG／输入摘要与第三方日志时验证脱敏；独立脚本静态检查不打印 Key 片段。
3. 人工下载响应覆盖证书失败、有限超时重试、HTTP 错误、流中断、旧文件保留、成功原子写入及响应关闭；不访问外部地址。
4. 全量后端／前端测试、类型检查、Lint、生产构建；运行真实子进程重启恢复回归，比对开工时业务文件哈希。
5. 桌面及移动代表页只读检查；证据包在 `docs/evidence/阶段3/模型缺陷修复/`，含截图、核对步骤和十项闸门；不放日志或命令输出。
6. 更新 README、项目状态和本开发文档结果，审查差异及秘密排除，最后本地提交，不推送。
