# 阶段 3 第 5 子阶段：生成计划界面

2026-10-05。先形成本文，再开发，验证及证据交付后本地提交。依据 PRD F06／F07、既有生成计划合同与项目状态；沿用阶段 3 前端手册和现有视觉方向。

## 前端适配声明与范围

新增项目内 `/projects/[projectId]/plans`，从素材页进入。显示持久化计划、固定版本、分镜内容、变化影响、费用待确认和执行阻断。沿用创作工作室深色／浅绿、现有 Next／React 和受控媒体地址，无新依赖、平台或费用。

本轮创建表单每次选一个已有片段，支持首帧、首尾帧、1—4 张参考图和可选文字定义；后端既有多片段计划完整展示。模型名称取项目已有设置或用户明确填写，保存只是本地规划，不代表模型能力已验收。无分镜、无适用引用时引导回项目／素材页。修改需创建新计划，保留历史。仅本地输入确认与手动输入检查；不接费用确认、授权签发、任务创建、真实发送、后台执行或账号部署。

## 用户流程与状态

1. 读取列表、项目及引用；选记录后 URL 保留计划编号，刷新／浏览器历史恢复选择。
2. 新建时明确片段、时长、模型、画面参数及引用用途。引用限定当前项目及该片段／镜头，固定所选引用版本，不自动采用最新版本。
3. 保存后看完整计划，再勾选“已核对本地输入”并点击确认。后台保存内容摘要与确认，明确费用和真实执行仍待确认。
4. 手动检查本地输入，成功显示可读提示词与图片数量；不产生任务或调用模型。确认、检查只对当前且新鲜读取的计划开放。
5. 仅新增版本显示提醒；引用／分镜变化显示失效原因，阻止确认和检查。可回素材页调整引用，再另建计划。

加载、空列表、未选／不存在、缺分镜、缺引用、草稿、已本地确认、旧版本提醒、已失效、读取失败／提交结果不确定、媒体失败分别呈现。读取故障保留旧数据并关闭写操作，重新读取后才恢复。历史所属项目不存在时保留计划只读。表单退出提示未保存；忙碌期间禁止退出／重入。同步锁防重复点击，写请求不自动重试，结果不确定时保留表单并要求重读核对。

## 请求、响应与错误合同

| 请求 | 响应 | 校验与边界 |
| --- | --- | --- |
| GET /api/project/{id}/status | ProjectSnapshot | 项目匹配；404 视为历史项目缺失，其他错误阻止操作 |
| GET /api/assets；GET /api/project/{id}/asset-references | Asset[]、AssetReference[] | 复用结构校验、引用与版本对应；仅创建时要求存在 |
| GET /api/project/{id}/generation-plans | PlanView[] | 编号唯一、项目匹配、固定绑定／模式／状态／影响一致 |
| POST /api/generation-plans | PlanView（201） | project_id、options、targets；明确 role；保存后校验返回请求对应 |
| POST /api/generation-plans/{id}/confirm | PlanView | content_hash、local_only=true；确认只允许 local_input_only，返回编号／摘要一致 |
| POST /api/generation-plans/{id}/dry-run | PreparedPreview | 无正文；只显示当前计划匹配的本地预览，不渲染后端文件地址 |
| GET /api/assets/{id}/versions/{id}/media | 固定版本图片 | 不使用任意外链／私有路径，失败可重新加载 |

统一错误 `error.code/message`。浏览器请求设超时，无自动重试；400／404／409 安全呈现，500／断线／成功但响应异常的写入均标记结果不确定。新建后不自动确认或检查，浏览／刷新不做 POST。

## 实施与验证

新增集中类型／解析／表单构建器、项目计划组件及样式、路由、素材页入口和同源计划转发。生产后端合同和存储结构保持；新增独立 `plan-center-demo` 人工服务，仅资产／计划接口及只读项目状态，无模型或任务路由，样例明确人工，独立忽略目录，重启不重新播种。

测试重点为非法合同拒绝、角色数量／作用范围、版本锁定、未知费用、确认边界、无 POST 读取、提交不确定不重试、恢复一致性。实际浏览器检查 390／768／1280／1440，保存→明确确认→手动检查→刷新，新增版本及引用升级后失效、失败恢复；独立 HTTP 服务重启后保留计划和确认。快照核对原业务文件无变化。运行全量后端／前端回归、类型／Lint／生产构建与秘密排除检查。
