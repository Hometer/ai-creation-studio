## 现有页面问题

首页留白与工具控件占主导，视觉层次偏平均，六张灵感画面只被放在普通矩形卡中。原有首页隐藏顶栏，缺少“创作／灵感／项目”的清晰路径；历史为空时整个项目区域消失，接口失败也容易看成没有项目。历史恢复主要依赖鼠标，标题和状态区较弱。灰白页面、黑色按钮和各处蓝色状态不够统一。

## 推荐方向

采用深色电影创作工作室。保留小云雀名称与现有标识，底色 #101114、侧栏 #151619、卡片 #1c1e22，主要文字 #f2f3f5，次要文字 #a9afb8；主动作使用柔和黄绿 #c5f277，状态保留青／绿／琥珀／红语义。系统中文字体，正文 14—16px，主标题桌面 38—44px／手机 28px；8px 间距节奏、卡片圆角 16—20px、输入框 20px。画面与留白承担吸引力，避免全屏渐变和大量发光装饰。

| 区域 | 设计与实际操作 |
| --- | --- |
| 导航 | 中文品牌与创作空间；首页内创作、灵感、项目锚点；原工作台、三类流水线和设置入口保留；手机抽屉 |
| 首屏 | 左侧创作标题与说明，右侧已有太空画面作为灵感封面；自然语言输入置于主要位置，主操作“保存创作草稿” |
| 输入 | 关联 label，普通 Enter 换行，Ctrl／Command+Enter 保存草稿；上传、剧集与高级配置仍可使用；原逐步／一键生成保留为明确次级入口，不自动触发 |
| 工具 | 临时工作台、文艺短视频、动作迁移、数字人口播四个可点击捷径，链接到现有页面，不虚构能力 |
| 灵感 | 六张本地画面卡；分类筛选、悬停“使用灵感”、点击回填并聚焦输入；静态样例明确为灵感封面，不伪装成用户作品或视频 |
| 项目 | 独立“我的项目”区域，检索、状态、进度、键盘可打开、管理与删除确认；加载、错误及空状态各自明确 |
| 工作台 | 统一顶栏、分阶段标签、面板／输入／按钮和弹窗表面；不重写六阶段生成逻辑或假造任务产物 |

“保存创作草稿”调用已有项目创建接口，只持久化故事与参数，不执行阶段、不调用模型。这样本轮可以用真实后端验证保存→打开→刷新→重启恢复，也让尚未配置模型的创作者有可用的入口。实际生成按钮仍属于原有功能，验收时不点击，模型效果仍待验。

## 范围与验收

本轮实现一个完整首页代表页，并统一现有页面外壳与设计变量；不新增社区、资产编辑页面、画布、时间线、会员或虚构生成结果。用户已授权文档完成后开发及提交，本轮不再次要求确认已给出的参考方向。

390、768、1280、1440px 检查首页、项目工作台、配置面板及既有四类工具／设置页面。浏览器核验样例筛选与回填、草稿真实保存、刷新恢复、错误重试、手机抽屉与键盘操作。已有前后端测试保留，运行类型／Lint／生产构建；交付前后对照与桌面／手机截图。视觉感受由产品经理查看代表页后反馈；本轮工程交付不代表真实生成或整体项目验收。
