# 阶段 2 第 2 子阶段：本地文字资产与版本引用

日期：2026-10-04。本文先于本轮代码形成，按产品经理“继续下一步，先文档再开发，完成后提交”的授权实施。

## 本轮交付范围

承接上一轮建议的资产与版本切片，实现 PRD F03、F06 的本地后端基础。角色、场景、道具可人工建档；现有 `script_generation` 中的角色、场景文字定义可显式导入。每次修改追加不可变版本；项目、分镜片段或片段内镜头可引用指定版本。更新资产后，旧引用保持原版本，查询提示有更新；升级或回退引用必须显式提交并记录历史。

本轮不调用模型，不创建云资源，不上传素材，不自动修改旧项目或原有 `selected` 媒体，不自动重新生成。图片、视频文件的归档、生成输入接线、费用确认界面和正式资产页面留给后续切片。文字版本与引用链验收不代表完整 F03—F08 或整个阶段 2 验收完成。Q2—Q5 的范围、预算、隐私和交付决策保持待定；下一收费或对外交付步骤必须先关闭相关问题。

## 技术适配与持久化

扩展现有 FastAPI/Pydantic 后端，保留原目录、会话 JSON、前端和所有原路由。无新增依赖、数据迁移或收费平台。使用独立 `backend/data/asset-library/library.json`，已被根 `.gitignore` 的 `data/` 排除；该位置不在 `/code` 静态目录下。

资产、版本和引用在同一文档中提交，写入采用临时文件、fsync、原子替换；读写均经过进程间文件锁。每次操作从磁盘加载，写入失败不保留内存副本。文件锁支持本机多个进程，目标为 macOS/Linux 本地运行；暂不支持 Windows 或分布式共享文件系统。避免为本轮的小型本地库引入数据库迁移。若将来多人服务或数据量增长，再评审数据库和账号隔离；当前默认启动只监听 127.0.0.1。

文档 `schema_version=1`，严格校验资产 ID、版本序号、引用关系、引用历史与导入来源唯一性。损坏、未知版本、符号链接文件不被静默覆盖，统一返回安全错误，不回显路径、用户内容或堆栈。数据目录不存在时按需创建，不能自动重置已有库。

## 数据合同与约束

- Asset：随机 `asset_id`、固定 `kind`（character/setting/prop）、按序追加的 `versions`、可选导入键。没有删除或覆盖历史接口。
- Version：随机 `version_id`、连续 `number`、名称、文字定义、时间和来源。名称 1—100 字，定义 1—10000 字，去掉首尾空白；拒绝未知请求字段。无文件路径、任意 URL 获取或上传接口。
- 来源：manual 或 script；导入来源记录项目 ID、脚本阶段、条目 ID 和角色／场景分类。导入既有结构化条目，定义保存为可读 JSON 文字，保留条目内容。重复导入相同条目且内容不变时返回原最新版本，变化时在同一资产上追加版本；旧引用不动。
- Reference：随机 ID、资产 ID、指定版本 ID、项目 ID、可选 segment_id 和 shot_number、连续 revision 与完整版本选择历史。镜头编号为正整数，必须与片段一起填写。仅允许引用确实存在的项目、片段、镜头和资产版本；同一资产与位置不能重复建引用。
- PATCH 引用必须提交 `expected_revision`，不匹配返回 409；允许显式升级或回退，重复提交当前版本不产生虚假历史。历史字段不得由客户端覆盖。
- 查询返回 `has_newer_version` 和 `target_exists`。项目或分镜被原流程移除后，历史引用保留并标明目标缺失，不创建虚假项目，也不删除库中资产。

## 接口合同

所有接口沿用 `{"error":{"code","message"},"detail":"兼容旧客户端"}` 的错误结构，OpenAPI 声明请求与响应。422 表示字段错误；404 表示资产、版本、项目或目标不存在；409 表示冲突；503 表示库不可读、未知结构或持久化失败。错误不包含提交正文。

| 方法与路径 | 请求 | 成功响应 |
| --- | --- | --- |
| POST /api/assets | kind、name、definition | Asset，201 |
| GET /api/assets | 无 | Asset[] |
| GET /api/assets/{asset_id} | 无 | Asset |
| POST /api/assets/{asset_id}/versions | name、definition | Asset，201 |
| POST /api/assets/import-script | project_id、kind（角色／场景）、item_id | Asset，200；重复导入幂等 |
| POST /api/asset-references | asset_id、version_id、project_id、可选 segment_id/shot_number | ReferenceView，201 |
| PATCH /api/asset-references/{reference_id} | version_id、expected_revision | ReferenceView |
| GET /api/project/{project_id}/asset-references | 无 | ReferenceView[] |
| GET /api/assets/{asset_id}/usage | 无 | ReferenceView[] |

这些引用是可追溯的准备记录，本轮不会用于旧模型调用。前端继续原流程；可在本地 `/docs` 的“资产与版本”接口分类操作。
