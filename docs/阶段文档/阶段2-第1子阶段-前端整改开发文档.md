# 阶段 2 第 1 子阶段补充开发文档｜前端工程整改

日期：2026-10-04。本文先于本轮代码修改编写。配套 `前端技术适配声明-现有工程整改.md`、上轮代码整合开发文档。

## 1. 本轮目标与范围

关闭全量 Lint 遗留问题，保证现有项目可在手机查看阶段与配置、打开和关闭侧栏，保持原页面、输入、选择和 API 行为。完成文档、代码、验证与证据后做本地 Git 提交。

处理组件、API 与数据类型、Hook 闭包和生命周期、不可变更新、渲染 ref、侧栏、顶栏和配置面板。所有 ESLint 规则继续生效；不删除功能、测试或用户数据，不通过断言链或 any 别名规避类型。不改变模型、后端数据格式或原流式协议，不扩展资产／画布／3D／账号／部署功能。

## 2. 用户流程与状态

进入现有项目 → 从后端恢复阶段与参数 → 查看待生成状态 → 切换阶段 → 打开生成配置 → 关闭配置 → 手机打开侧栏 → 导航到工作台或流水线 → 关闭抽屉后继续填写输入。验证不点击收费生成或重要删除。

| 模块 | 初始／加载 | 空／待开始 | 恢复 | 错误 |
| --- | --- | --- | --- | --- |
| 项目 | 原加载提示 | 保留 pending | API 的阶段、参数与选择 | 安全提示，保留输入 |
| 侧栏 | 服务端默认与客户端媒体状态一致 | 手机默认关闭 | 桌面偏好与手机抽屉分别处理 | 本地偏好存储不可用时可继续操作 |
| 模型与模板 | 请求完成前不提前判空 | 真实列表为空才提示 | 已保存值保留 | 保留原错误提示与恢复入口 |
| 流水线／工作台 | 恢复对应 URL 任务 | 原表单保持 | 清理旧请求／订阅，避免串任务 | 原失败状态保持 |

## 3. 契约与实现

普通接口保留 URL 与成功响应，读取统一 `error.message` 并兼容旧 `detail`。会话、生成参数、任务、媒体项及阶段产物在 `lib/` 与原阶段类型中定义；动态修改请求使用 `Record<string, unknown>`，显示数据采用明确字段。外部解析、异常和不确定扩展字段按 unknown 收窄，不信任 JSON 的隐式 any。

异步 effect 需取消／失效标记，轮询与事件订阅卸载时释放。选项列表变化以派生数据或带数据标识的编辑状态同步，不借微任务或定时器隐藏同步 setState。可变 ref 仅用于事件和异步流程，渲染数据用 state／props；后端仍是项目状态事实来源。

侧栏采用媒体查询一致的桌面展开与手机抽屉：手机主区域 margin 与顶栏 left 始终为 0，抽屉开时提供关闭遮罩、Escape 与导航后关闭；关时移出视口且不可聚焦。顶栏业务阶段与控制区分行，横向阶段滚动仅限导航容器。配置面板在视口内滚动，不遮住无法触达的底部操作。

## 4. 验收

1. 全量 `npm run lint` 无错误，处理可修复警告；strict 类型检查、已有及新增测试、生产构建通过。
2. 根目录 `scripts/project.py check` 完整运行通过，不改变检查规则。
3. 真实后端下核对六个现有页面；手机与桌面均无全页横向滚动、顶栏状态／配置入口裁切或关闭后的侧栏遮罩。
4. 对真实人工测试项目刷新后阶段和模型参数不丢；切换阶段、配置及抽屉后数据保持。浏览器没有持续异常，未触发模型费用。
5. 图片与视频预览组件保留动态 URL 支持；自动化覆盖典型人工产物结构与选项处理，但不冒充真实模型生成或多媒体效果验证。
6. 提交前扫描变更与前端构建，秘密、用户数据、缓存不提交。更新 README、项目状态与 `docs/evidence/阶段2/前端整改/` 中的截图、步骤和闸门表。

## 5. 风险、回退与交接

类型补全和 Hook 改造涉及已有生成界面，需用与后端结构一致的人工样例覆盖转换和选择逻辑，保留真实效果待验标记。局部修改保留原路径与契约，必要时可以按 Git 提交回退；不迁移用户数据。下一业务切片先定义资产、版本、引用与费用计划文档。整个阶段 2 的真实生成验收仍受 Key、预算与业务决策限制。


## 6. 实施记录与边界

- 原有 Lint 135 错误、39 警告已全部关闭，删除原视频页的 Hook 规则豁免，没有新增规则豁免或依赖。
- 页面与请求共享显式类型；恢复接口校验状态外层结构、配置标量、历史时间与进度，事件流校验事件类型及基础载荷，普通写接口兼容 `error.message` 和旧 `detail`。这是本轮恢复边界校验，阶段产物内部继续沿用各自既有结构，不视为全部模型输出校验已完成。
- 项目恢复改为 URL 驱动的异步请求，过期恢复结果不写入当前页面；轮询用独立令牌，离开时失效。阶段组件以项目和阶段作为标识，避免不同项目之间复用编辑状态。工作台任务进入历史后停止轮询，流水线订阅和模型目录请求卸载时失效。
- 模板选择按当前比例派生有效模板，自定义字段关联模板标识。保留收费启动入口，但测试只检查选择和展示。
- 媒体图片通过 `MediaImage` 保留直接 URL，使用已有 Next Image 且关闭服务端优化，不新增收费代理或远端域名限制。六阶段展示及旧图片／视频映射都有人工样例回归。
- 手机主内容在抽屉打开时不可聚焦，支持遮罩、Escape、导航关闭与焦点返回。顶栏按窄屏分行，实际高度由 ResizeObserver 同步占位，运行按钮增加时允许控制区换行。
- 全量检查通过。浏览器模拟 35 个页面／宽度组合通过；真实生成、真实生成中操作、实体手机与长期任务续跑仍待后续验收。
- 交付证据与闸门表见 `docs/evidence/阶段2/前端整改/验收报告.md`。
