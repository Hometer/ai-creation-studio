# 文字版本导出与备份开发文档

日期：2026-10-05。阶段 3 第 12 子阶段，先形成本文再开发。按用户确认的下一步实现，沿用前端风格、版本数据格式和本地单用户／单写服务；不替换技术栈，不新增依赖。

## 范围与默认方案

现有文字版本页增加“导出与备份”区，提供“下载 JSON 备份”和“下载可读 TXT”。默认一次导出当前剧本、当前分镜及该项目全部已归档文字版本，原因是保留完整历史比逐条下载更便于离线留存。格式为 UTF-8；保留中文、换行、空文字、null、数字／布尔值、未知附加字段、章节／镜头结构、版本来源、时间与恢复关系。

当前正文与归档历史分别输出；没有历史的已有正文也能下载，空项目明确提示空文字且不创建基线。存在未归档变化时标记当前正文尚未归档，不把它称作某个历史版本。读取中或保存依据不可靠时暂停下载。编辑草稿不进入导出，下载不清空草稿／预览、不改变选版。

文字备份不是完整项目备份：没有媒体文件、资产库、任务、计划、费用、人工核对记录、会话 meta、进度、错误、系统配置或内部请求幂等字段。只复制两阶段完整正文快照和白名单历史元数据；不是原始会话文件下载。不开发导入恢复、清理／删除、定时备份、云上传、ZIP、付费或模型调用，不改变待定留存规则。下载格式与范围属于用户已授权工作的实现默认值，不新增业务范围。

## 接口与文件契约

- GET `/api/project/{project_id}/content-revisions/export`，查询 `expected_token` 为当前工作区 64 位摘要，`format` 必填且仅 `json`／`text`。只从当前项目读取，不接受路径、跨项目版本列表或文件名参数。
- 同一引擎锁内读取磁盘并校验缓存／历史，用工作区摘要检查依据；过期返回 409，项目不存在 404，非法请求／不支持的旧结构／超限 422，损坏或存储不可用 503。错误统一 `error.code/message`，不显示正文、堆栈或私有路径。
- 成功为 `application/json` 或 `text/plain; charset=utf-8` 附件。安全固定前缀＋校验过的项目 ID＋摘要前 12 位＋扩展名；`Cache-Control: no-store`、`X-Content-Type-Options: nosniff`；响应头含完整导出依据、格式、版本数、`X-Export-Bytes` 原文件 UTF-8 字节数和文件 SHA-256。文件内容不记录日志。
- JSON 包的 `format` 固定为 `text-revisions`、`schema_version` 为 1，含项目 ID、依据、两阶段当前 content/digest/version_id、白名单 versions 和 untracked_stages。归档记录保留 version_id/number/stage/source/created_at/content/digest/changes/impacts/restored_from，不含 request_id/request_digest。当前版本 ID 只有与最新归档完整摘要一致时才填写；其余为 null。没有导出时间字段，确保同一依据重复导出及服务重启后文件字节一致。不是可直接覆盖会话文件的格式。
- TXT 开头固定产品／项目／依据／范围标识；逐份显示当前及归档版本的可读文字、来源／编号／时间／恢复信息，附完整 JSON 结构及差异／影响信息。附加字段不会因未在编辑器展示而丢失；依据以 JSON 完整结构为准。
- 单文件最多 64 MiB，包括 UTF-8 编码后的最终内容。达到上限明确拒绝，不截断、不改业务数据。写入／编辑历史原上限保持；导出不要求正文必须可编辑，不用 500 字段编辑上限阻止留存。仍只支持两阶段字典快照，非字典旧产物保留并给安全提示。

## 前端读取与交互

集中下载客户端只发一次 GET、no-store、20 秒截止、无自动重试；流读取实际字节数受 64 MiB 约束，校验文件类型、依据、版本数、文件名、SHA-256，拒绝截断、坏响应和串项目／格式。JSON 额外校验契约、版本身份与工作区、当前／归档关系、正文可读字段；TXT 校验固定头与版本数。响应正确后创建 Blob 附件交给浏览器，及时清理对象 URL。

实际浏览器接线发现 Next.js 代理会 gzip 压缩并删除 Content-Length。浏览器 Fetch 返回解压后的字节，因此完整性校验使用必需的 X-Export-Bytes 原文件长度及 SHA-256；压缩传输长度不当作文件长度。未压缩且有 Content-Length 时要求与原文件长度一致，仍逐块限制真实读取大小并拒绝截断。

只在明确点击时下载。加载时禁止重复按钮；失败保留项目、选择及草稿，可手动重试。过期提示先重新读取，重读继续使用原草稿放弃提醒；组件卸载或工作区变化后不触发迟到下载。下载是留存动作，不要求放弃编辑草稿；原导航离开仍提示。

状态说明包括历史条数、空文字、当前正文未归档、下载中、失败与已交浏览器下载。下载回执不承诺用户已将文件保存到指定磁盘位置，提示查看浏览器下载目录。桌面并排按钮，手机可完整阅读和操作；保留定向编辑、恢复、对比和人工核对入口。
