# 阶段 2 第 5 子阶段：费用确认与持久化任务恢复

日期：2026-10-04。本文先于本轮代码形成。依据 PRD F07／F08、第 4 子阶段的固定计划与输入适配。产品经理已确认“本轮先不收费调用”，继续先文档、再开发、检查后提交。

## 一、目标与边界

实现本地纵向链路：固定计划 → 单片段报价 → 保存人工费用确认 → 建立任务 → 预算预留并入队 → 分步提交／查询／结果归档 → 重启恢复。任务粒度沿用 segment；一个报价对应一次该片段生成，重新生成须新报价和确认。原六阶段／原模型客户端和用户数据保留，不把新闸门声称为旧付费接口的统一改造。

主应用未配置真实报价或执行适配器，新接口保存未知报价和阻塞任务，未知费用为 null、不能确认或入队。本轮不调用模型、不发送真实素材、不新增云资源、正式前端或账号。本地演练入口使用明确标记的模拟平台和 SIM 点数，以可读取的人工 MP4 检查归档；SIM 不代表人民币、平台价格或真实扣费。真实厂商／额度、隐私／留存、交付方式与完整范围仍待定。

## 二、技术适配

沿用 FastAPI、严格 Pydantic、已有工作流快照和资产库进程锁／原子保存；不新增依赖或数据库迁移。本地单工作流写进程边界保持。报价、确认、任务和预算账务在一个 `backend/data/asset-library/generation-tasks.json`（独立 schema 1）内原子提交，预算由已保存任务预留／结算计算，避免“任务写成功但额度没占”的半提交。资产与计划原文件不改结构。

新模块 `api/schemas/generation_tasks.py`、`core/generation_tasks.py`、`core/task_provider.py`、`api/routers/generation_tasks.py`。工作文件在资产库私有 task-output 目录，媒体结果复用归档模块；目录不挂到 /code，不进 Git。存储需拒绝损坏、重复 JSON 字段、未来 schema、摘要／关联不符、非普通文件和链接，错误保留原文件。备份需保留会话及整个资产库；多人事务与分布式租约未来另行适配。

## 三、报价、确认与预算

报价绑定 plan_id、content_hash、segment_id、模型／模式参数、有效期和服务端价格依据。价格由后端提供，不接受客户端单价、币种、费用、可信状态或平台配置。主应用只产生 unavailable 报价与 null；演练服务只支持 local-test-model，用人工规则 2 SIM／秒，报价的 pricing_kind=simulation、currency=SIM、说明为“人工演练，不代表平台报价”。

确认请求明确报价摘要、单次上限、项目总上限、simulation_only=true。只允许确认当前且已确认内容的计划、未过期的模拟报价；不允许把 unknown/null 当零元确认。整数点数计算，不使用浮点金额。确认保存时间、摘要、预算上限和 simulation_only 范围；相同确认幂等，修改上限需新报价重新确认，旧记录不覆盖。

任务入队时在同一锁内核对计划／媒体、报价、确认与剩余额度，预留本次上限；并发任务不能穿透项目总上限。预留与已结算消耗分别记录；不确定提交或未知费用继续占用预留，不自动退还。平台明确给出有效最终消耗时结算，超过报价上限或无效消耗转人工核对；未知实际金额不能写零。模拟明确失败可结算 0 SIM，但不把这个规则当真实平台退费政策。日／月真实额度在厂商与预算确定后设计。

## 四、任务状态与重复提交

任务保存 task_id、request_id（客户端幂等键）、报价／计划摘要、项目／片段、revision、状态、平台编号、提交／查询／归档次数、租约、错误 code/message、预算记录与结果资产版本。相同 request_id 和相同报价返回原任务；同键不同报价冲突。一个报价只能建立一个任务，不能重复批准消费。

状态为 blocked → queued → submitting → submitted → running → fetching → succeeded；明确失败为 failed；不确定或无法安全恢复为 manual_review。错误只保存白名单 code/message，不记录请求全文、完整 Prompt、路径、密钥、平台原始报错或堆栈。

入队和 queued 第一次提交前检查来源变化；已提交任务继续追踪其原固定输入，不因分镜后续变化自动重发或取消。任务先落 submitting 与租约，再调用平台，成功后立即保存平台编号。活动租约禁止并发推进；每次推进只做一个有界步骤，提交最多一次。提交超时／失联不能重新 submit；租约到期后的 submitting 或不确定状态只能按平台编号／幂等键查询，查不到转人工核对。

查询／结果读取允许最多 3 次连续失败，保留错误和预算；达到上限停止自动动作。查询总次数有界。SDK 初始化亦在兜底范围内；默认正式服务没有适配器，确定性地禁止执行。服务重启读取原状态和租约，不默认为重新生成。平台支持幂等查询是模拟契约，不声称真实厂商都支持；无法查幂等键的真实平台须人工核对提交窗口。

## 五、执行与输出合同

后端适配边界区分 submit、query、fetch_result，结构化校验任务编号、状态和最终消耗。现有 VideoClient 是同步“提交＋等待＋下载”封装，缺少可靠持久化检查点；本轮不直接包它来冒充可恢复执行。后续真实平台必须分别适配、验证原生超时／重试、报价和提交不确定窗口。

本轮唯一可执行实现是独立目录的持久化模拟平台，提交和查询记录保存在其 schema 1 文件并加进程锁；模拟任务编号和查询计数重启后恢复。仅复制本地 ffmpeg 人工 MP4，不请求外网。接口步进不无限等待；租约 30 秒、适配器单步合同上限 10 秒；未来真实调用必须实现原生超时。本轮演练用即时本地操作和超时／失联测试，不替代真实网络验证。计划的 5 秒仅用于参数和 SIM 账务演练，输出固定为 1 秒人工色块 MP4；不验证模型效果、实际生成时长或声音。

结果须经原 MP4 容器、大小、ffprobe、SHA-256 校验再归档。资产版本新增 generation_task 来源，记录项目／片段、task_id、plan_id、content_hash、simulation_only=true；旧 artifact／文字来源兼容。不同任务追加版本，即使人工视频字节相同也保留任务来源；同一任务重复归档复用原版本，且不因另一任务先归档而丢失幂等。归档成功、任务写回前若进程结束，恢复读取按 task_id 找到已归档版本，不产生重复版本。即使最后一次归档重试已用尽或适配器暂不可用，仍可核对已归档本地结果并补写成功状态；不会再次查询或下载。成功任务只提供受控媒体 URL，不改变旧 selected。

## 六、API 合同

保留 /api 前缀和统一 `{"error":{"code","message"},"detail":"兼容字段"}`；每个接口定义请求、响应和错误。采用提交任务＋读取快照＋显式分步推进的后端 MVP 验收方式，不新增 SSE、后台无限轮询或正式任务页面。

| 接口 | 请求与结果 |
| --- | --- |
| POST /api/generation-quotes | plan_id、segment_id；201 QuoteView，显示价格依据／有效期／摘要／确认 |
| GET /api/generation-quotes/{quote_id} | QuoteView，包含 current／expired／offer.pricing_kind，不删除历史 |
| POST /api/generation-quotes/{quote_id}/confirm | quote_hash、max_amount_minor、project_limit_minor、simulation_only=true；保存本地演练费用确认 |
| POST /api/generation-tasks | quote_id、request_id；201 TaskView，未入队 blocked，可重复读回同键原任务 |
| GET /api/generation-tasks/{task_id} | TaskView；状态、次数、预算、错误与结果 URL，查询不推进平台 |
| GET /api/project/{project_id}/generation-tasks | 保留的任务列表，无项目也保留历史 |
| GET /api/project/{project_id}/generation-budget | BudgetView，未知报价没有可消费币种／额度，演练为 SIM |
| POST /api/generation-tasks/{task_id}/enqueue | expected_revision、quote_hash；检查确认／当前输入／额度并原子入队 |
| POST /api/generation-tasks/{task_id}/advance | 无正文；一次提交／查询／归档或恢复，不重复提交；终态读取幂等 |

422 严格结构／未知字段，404 计划／片段／报价／任务不存在，409 摘要、确认、过期、来源、预算、幂等冲突、活动租约或适配器不允许执行；503 存储／媒体异常。平台失败以 TaskView 中受控失败／核对状态持久化，基础设施保存失败仍返回统一 503。客户端不能指定状态、平台任务编号、价格或输出路径。
