# 前端体验升级技术适配声明

2026-10-05，先于代码。配套 [调研与设计方案](前端体验升级-设计调研与方案.md) 与 [阶段开发文档](阶段3-第1子阶段-前端体验升级开发文档.md)。

## 项目判断与输入

已有小云雀 Next.js Web 应用，主要用户为独立短片／短剧创作者，桌面为主、移动浏览器基本可用。本轮业务目标是使首页具备吸引力，并清楚完成灵感选择、草稿保存和已有项目恢复。已读初版 PRD、项目状态、现有接口与核心代码、前端手册全文及本轮公开设计参考。完整 PRD 范围、真实效果、登录与留存仍待定，不阻碍现有本地单用户页面的视觉迭代，不把本轮当上线或多人产品。

## 技术选择

沿用 Next.js 16.3、React 19.2、TypeScript strict、Tailwind 4、Lucide、现有 npm 锁文件。语义 CSS 变量与页面组件实现，无依赖升级或新组件库。沿用集中 workflowApi、原 SSE／轮询及服务端状态，不改模型调用、任务契约或既有数据结构。新增草稿保存包装只调用已有 startProject，不执行 workflow stage；请求防重和失败后输入保留。

组件 state 保存未提交输入、筛选和弹窗，URL 保存项目／阶段位置，后端保存草稿和工作流真实状态。未提交内容离开前不声称已保存；显式保存后可跨刷新／服务重启恢复。Node test 加载真实 TypeScript 模块做行为与渲染验证，ego-browser 真实浏览器验收；沿用已有方案，不为符合默认 Vitest／Playwright 模板迁移测试。

## 页面、状态与边界

核心为原 `/` 首页和 `/?session=…&stage=…` 项目工作台。原 `/sandbox`、三种 `/pipelines/*` 与 `/settings` 保留，统一外壳、表面及控件。图片使用现有本地封面；真实动态图片和视频仍走已有受控地址。任务 pending、running、waiting、completed、error、stopped 沿用已验证映射，绝不由动画或保存成功推断生成成功。

首页项目区显示加载、空、读取失败可重试、筛选无匹配及实际项目列表。提交时禁用重复操作，错误就近显示；删除保留人工确认并增加焦点约束。移动抽屉关闭不残留遮罩，Escape 关闭并返回焦点；配置可滚动，不撑破视口。390／768／1280／1440px 均验收。

用户明确要求模型后置、先优化前端。本轮据此优先实施现有应用体验，不引入尚未验证的新生成能力、正式上线、费用开关或身份系统。没有需要重新询问的业务决定；模型额度、效果、登录、留存仍按状态台账待定。交付工程检查与证据，真实模型闸门继续待验。
