# 阶段 3 第 7 子阶段：定向修改与版本回退

## 1. 目标与依据
2026-10-05，产品经理授权继续下一切片，并要求先文档、开发、验证后本地提交。承接执行前准备界面，补 PRD F02 的指定内容修改和旧版恢复、F06 的文字版本追溯。真实模型继续后置；整体阶段 3 仍待业务、真实模型和真机验收。

## 2. 本轮范围
新增项目“文字修改与版本”页，选择已有剧本或分镜中的一个文字字段，修改前由服务端给出旧值、新值及保守影响清单，用户确认后保存为新版本。历史版本可查看，并先预览、再确认恢复为新的当前版本。其他文字、素材候选、视频选择和已有计划记录保留。没有模型调用、外发、自动生成、费用或自动继续流程。

支持已有字符串字段：剧本标题／梗概／节拍大纲、章节正文、场次剧情；分镜片段提示词、镜头内容／剧情／台词。数字、标识、结构增删及没有对应字段的旧结构在本轮只读。历史从第一次通过本入口修改前开始；原页面及模型的既有编辑能力保留，不宣称追溯以前未记录的版本。检测到原入口更新时提示重新核对，并在下一次本入口保存时归档该时点的内容。

## 3. 用户流程与状态
项目素材页进入文字修改页 → 选对象 → 填新内容 → 预览差异及影响 → 勾选本地修改确认 → 保存 → 刷新仍能查看新旧版本 → 从历史选择旧版 → 预览整阶段恢复范围 → 确认形成新版本。回退只覆盖选定的剧本或分镜阶段，另一阶段和媒体完全保留。

加载、空内容、历史缺失、项目 404、读取失败保留旧数据、提交中禁用、预览过期／并发冲突、回复不确定与重新读取均需可辨识。编辑草稿仅在页面内存，离开提醒；不把完整文档放入浏览器存储。历史选择放 URL，刷新及后退恢复；不自动重发写请求。

## 4. 契约
GET /api/project/{project_id}/content-revisions：只读工作区（当前校验令牌、允许修改的字段、版本元数据及内容、运行状态、保守影响记录）。
POST 同路径 /preview：{expected_token, stage, path, value} 或 {expected_token, stage, restore_version_id}，二者互斥；返回预览（签名令牌、差异、影响、目标内容）。不落库。
POST 同路径：同一预览输入 + {preview_token, request_id, acknowledged:true}。服务端重新计算预览和令牌，拒绝变化、运行中项目及无变化请求；同请求号同内容幂等，不同内容返回冲突。成功返回工作区和已保存版本号。
字段路径使用数组，字符串最大 10000 字，被编辑／恢复的单阶段内容 2 MiB、历史 32 MiB、允许字段 500 上限；超过上限阻止写入，保留历史。统一安全错误，404 不存在、409 过期／运行中／重号、422 非允许字段、503 损坏或存储失败。不回显异常和完整文档日志。沿用本机单用户，不声称上线隔离。

## 5. 持久化与边界
版本与当前内容在同一会话 JSON 原子写入，使用现有引擎锁，失败还原内存。新增可选顶层 content_history，旧文件兼容、读请求不迁移。首次写入同时归档基线；外部更新用摘要检测、下一次修改归档。所有历史留存，恢复追加版本而非删历史。当前令牌覆盖剧本／分镜与历史，防止并发覆盖和回退后的 ABA。

剧本修改缺少可靠场次到镜头映射时保守提示现有全部分镜；分镜单字段修改只列该片段／镜头及其参考图、视频、后期需核对。恢复列出该阶段全部变化路径并据此合并影响。仅记录待核对，不更改媒体、预算、任务、计划或旧工作流确认状态；已有计划依其自身输入签名判断是否失效。全链路自动依赖更新和对话模型下一切片再做。

## 6. 验收
自动化覆盖定向修改不扰动其余内容、回退保留历史、剧本与分镜隔离、只读不写、字段限制、并发与幂等、预览失效、活动项目阻挡、损坏数据、安全错误、原子写失败恢复和外部更新归档。前端解析、请求超时／未知结果、明确确认与 URL 恢复回归；类型、Lint、生产构建与全量测试。

浏览器使用 ego-browser skill，真实接口闭环人工文本样例，检查 390／768／1280／1440、加载／空／错误／成功、刷新／后退、断线和回复丢失。实际停止并重启独立人工服务验证版本与当前内容保留。原业务数据哈希核对，代码／构建／暂存区密钥排除。证据在 docs/evidence/阶段3/定向修改与版本回退/，交付截图、地址、照着点步骤和十项闸门。真实模型写待验，真机待验，不冒充阶段完成。

## 7. 风险与交付
现有生成仍可改变内容，预览后任何文字变更均使提交失效；本轮专属版本历史仅承诺本入口及捕获的外部时点。完整对话共创、结构编辑、收费重拍、全链路依赖处置、多用户和删除策略保持后续。独立 revision-demo 只挂载本轮本地接口，人工样例与原项目隔离，不删除已有数据。

工程交付结果：新增真实持久化文字版本服务、独立人工服务与项目页入口。版本和内容同一原子文件保存，失败还原内存；旧编辑入口仍可用，新增可选历史数据在统一读盘时校验，损坏或未来历史不被旧保存入口覆盖。修复旧 artifact 更新在保存失败后未还原内存的问题。

最终后端全量 724/724（新增 33），前端 201/201（新增 28）；类型、Lint 0 错误／0 警告和生产构建通过。首次回归有原重启测试启动超时，单独复查及最后全量均通过，未改测试时限或标准。浏览器完成分镜单字段保存、剧本保守影响、整阶段回退、刷新与 URL 后退／前进、其他窗口并发冲突、回复丢失只发一次保存、实际断线保留输入与恢复；修改后三次实际 HTTP 进程恢复分别保留 3、7、7 条版本，响应和会话文件哈希一致。四宽度六组状态 24 项及生产入口／错误页各四宽度通过；截图发现历史卡片收缩引起日期拥挤，修复后四宽度无重叠。原 165 个非日志业务／演练文件保持，主服务五个项目及其文字工作区可读。文档和证据同步更新，本地提交，不推送。

真实模型、效果评分、完整对话共创、全链路依赖处置、手机真机和业务验收仍待验，本轮工程交付不代表整个阶段验收通过。
