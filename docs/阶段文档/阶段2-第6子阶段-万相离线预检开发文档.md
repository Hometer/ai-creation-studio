# 阶段 2 第 6 子阶段：万相离线预检

日期：2026-10-04。本文先于本轮代码形成。前轮提交 c684432，后端 235 项、前端 33 项已通过。产品经理本轮确认先针对阿里云通义万相做本地预检，后续样例使用有权非敏感素材、境内处理；之前不收费调用的选择继续有效。

## 一、阶段目标

核对已完成的本地费用／任务链路，再交付一个可持久化、可重启查看的万相输入预检。链路为固定计划 → 本地规格／归档完整性检查 → 仅内存编译请求 → 保存脱敏检查结果 → 查看历史及是否仍符合当前计划。不会访问模型、上传素材、扣费、初始化 SDK 或打开真实执行。

只检查 wan2.7-i2v 及官方示例快照 wan2.7-i2v-2026-04-25 的首帧／首尾帧协议。参考生视频属于另一种契约，本轮明确报告尚未适配。旧模型、旧流水线和用户数据保留；不新增依赖、正式前端、后台 worker 或云资源。

## 二、依据与技术适配

沿用 FastAPI、严格 Pydantic、已有计划与资产文件锁／原子存储、Pillow 及媒体校验。模型标识取自固定计划；Endpoint 与 Key 仅由后端已有配置读取，公共报告只返回 Key 是否存在、Endpoint 的地域分类，不能输出 Key、原 URL、业务空间域名、磁盘路径、完整 Prompt、素材或 Base64。

官方资料核对日期 2026-10-04。规格快照标记版本，未来文档变化需重新核对，不把本轮预检当作实际平台认证或效果验证。

- [万相 2.7 图生视频 API](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference)：首帧／首尾帧媒体协议、图像／参数限制、北京及新加坡 Endpoint。
- [模型信息与公开原价](https://help.aliyun.com/zh/model-studio/wan2-7-i2v)：核对模型别名与快照；北京地域公开原价 720P 为 0.6 元／秒、1080P 为 1 元／秒。5 秒样例参考为 3／5 元，5—10 次独立成功样例参考为 15—30／25—50 元；未计额外生成和其他模型，不代表账户活动价格或已批准预算。实际调用前须核对账户报价与单次／日／月额度；本轮没有收费调用，也不把参考价格写成可执行报价。
- [异步任务管理](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks)：根据平台 task_id 查询原任务。
- [图生视频使用指南](https://help.aliyun.com/zh/model-studio/wan-image-to-video-guide)：异步查询与结果保存说明。

## 三、本地输入与请求合同

允许时长 2—15 整数秒、720P／1080P；Prompt 超过 5000 字符阻断，不静默截断。图像使用已归档明确版本，重新核对文件大小／SHA-256／图片头；宽高分别 240—8000、比例 1:8—8:1。保留本项目更严格的 10 MiB 上限。PNG 透明通道阻断，不擅自改图或换版本。

仅在计划已本地确认、来源仍当前、全部输入通过时，内存中生成标准 model／input.prompt／input.media／parameters 结构，图像为 data URI，不上传、不保存请求正文；摘要可用于核对同一输入。首尾帧各一张，角色映射严格。明确设置 prompt_extend=false、watermark=false，遵循固定内容与原模板；不能把静态默认当付费确认。

该版图生视频协议未声明声音开关、shot_type 和 ratio 请求字段。本轮不把它们塞入请求：sound=off 阻断以避免静默生成声音；镜头字段作为警告说明不透传、镜头意图来自固定 Prompt；视频比例与输入图不符时警告以输入图为依据、不能保证精确比例。不是所有计划参数都已验证生效。

输出分别显示 input_protocol_ready、局部错误／警告、请求摘要与图片版本元数据。配置中 Key 存在仅说明非空，不代表正确、已认证或已开通模型；地域分类也不能验证 Key 的地域。real_execution_allowed 永远为 false。真实报价／预算、真实适配器、真实认证与样例逐项审核继续作为阻塞项；SIM 账务不用于真实预检放行。

## 四、状态与隐私

新增 schema 1 `backend/data/asset-library/model-preflight.json`，与资产／计划共用锁和原子替换、目录同步。报告保存 plan_id、content_hash、项目、检查日期／规格版本、脱敏配置分类、片段与引用元数据、问题 code/message 和编译摘要。报告只保存观察结果，不保存新的付费确认或素材授权。

POST 新建报告，GET 读取历史并比较计划摘要／当前引用和脱敏配置分类；current 只表示这些状态与检查时一致，不代表重新检查图像字节；计划或相关分类变化，current=false，需要重新预检。Key 换成另一条非空 Key 无法仅靠存在性识别，所以报告始终显示 authentication_verified=false；不记录或公开密钥指纹。重要计划确认仍在旧文件，不改旧结构。损坏、缺字段、未来 schema、重复字段或链接返回安全 503、原文件保留。

已确认总体素材边界不等于每张素材版权／真人授权已核验。真实外发前还要逐次审阅样例及素材权利；本轮只读本地人工数据，不外发。留存／删除规则、真实调用额度与账号交付仍待定。

## 五、真实任务恢复设计

官方查询使用平台 task_id；没有确认可通过本地 request_id 找回任务的合同。由此采用保守规则：先保存 submitting，提交最多一次；收到 task_id 立即持久化，再按该 ID 查询。失联且未保存平台 ID 时转人工核对，禁止自动重发，不能套用模拟平台按幂等键查询的能力。任务／结果查询窗口按官方 24 小时说明准备，过期不自动重新生成。

真实适配应将提交、查询、下载分别实现；每步原生超时、有界查询／下载重试，提交失联不重试。当前同步 VideoClient 的提交重试和 wait 不能直接作为新恢复链路。暂不实现真实 HTTP 传输、真实报价与收费账本；未知消耗仍为 null，usage.duration 不能冒充扣费金额。

## 六、API

| 接口 | 合同 |
| --- | --- |
| POST /api/generation-plans/{plan_id}/wan-preflight | 无正文；201 脱敏持久化 ReportView；只读固定计划与本地文件 |
| GET /api/model-preflights/{report_id} | 200 历史 ReportView，含 current；不推进任务或编译新请求 |

沿用严格 32 位十六进制 ID、统一 error.code/message 和兼容 detail。请求体不是参数来源：POST 只允许空请求，客户端不能传 Endpoint、Key、价格、执行开关或状态。422 格式／未知字段，404 计划／报告不存在，503 存储异常。合法计划的输入／配置不通过仍生成报告，列明原因；不以 200／201 代表真实生成可执行。
