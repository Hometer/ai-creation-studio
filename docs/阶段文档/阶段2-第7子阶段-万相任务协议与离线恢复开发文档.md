# 阶段 2 第 7 子阶段：万相任务协议与离线恢复

日期：2026-10-04。本文先于本轮代码形成。基线为 91da2b7，后端 294 项、前端 33 项。继续遵守已定的“不收费调用、万相准备、有权非敏感素材境内处理”；不重新询问已定事项。

## 目标与边界

下一步完成 submit／query／download 协议适配，并用独立人工响应演练可恢复步骤。默认适配器关闭，只有明确标记的本地 fixture transport 可运行；本轮不实现或安装联网 transport，不读取真实 Key、不访问阿里云、不外发素材、不产生费用。协议适配通过不等于真实认证、原生网络超时或模型效果验证通过。

既有 SIM 任务服务及账本保留，不把真实 usage 换算成 SIM 或人民币。不接入生产执行路由、后台 worker、正式前端或新依赖，不改既有资产来源结构。离线演练结果是本地 ffmpeg 色块，保存在独立忽略目录，不作为生成资产导入。真实 HTTP 接入、账户报价、预算预留／结算与逐次素材审核仍为下一切片；预检中的 REAL_ADAPTER_NOT_IMPLEMENTED 继续表示尚无可执行的真实平台传输。

## 官方合同及本项目约束

核对 [图生视频 API](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference) 与 [异步任务管理](https://help.aliyun.com/zh/model-studio/manage-asynchronous-tasks)。提交 POST /services/aigc/video-generation/video-synthesis，要求 X-DashScope-Async: enable、JSON；沿用上一切片 WanRequest，不添加本地 request_id 幂等字段。查询 GET /tasks/{task_id}，必须具有平台 ID；request_id 仅用于平台排查，不能用于失联自动找回。

响应严格提取 task_id／task_status、usage.duration／video_count；忽略供应商扩展及 orig_prompt，原始 code/message 不入日志、公共结果或状态。六种状态 PENDING、RUNNING、SUCCEEDED、FAILED、CANCELED、UNKNOWN 分开处理；查询 ID 必须和提交 ID 一致。非法 JSON、字段类型、未知状态、成功但缺 URL、异常时长／计数全部拒绝。usage 仅为用量，amount_minor 与 currency 永远 null。

submit 最多一次；调用前原子保存 submitting。任何失联、异常响应或重启后 submitting 均进入 manual_review，不自动重发或按本地 ID 查询。query 最多 20 次，连续异常最多 3 次；download 最多 3 次，每次重新查询同一 task_id 获取临时 URL，不持久化签名链接；24 小时后转人工核对，不重新生成。每次 step 只推进一个有界步骤，明确保存 querying／downloading 检查点；查询与下载失联可重试，不重复提交。整个离线步骤持有跨进程文件锁；未来联网 worker 的租约接线不在本轮范围。

未来 transport 合同规定连接／读取超时及总期限、响应体上限、禁止自动提交重试／重定向。本轮 fake 按这些参数运行，验证期限及下载流中途异常；不声称已验证真实 socket 行为。

下载 URL 为内部瞬时数据，不入公共结果。项目采用保守策略：仅接受 HTTPS 的 dashscope-result-sh.oss-cn-shanghai.aliyuncs.com，禁止用户信息、端口、fragment、控制字符及非 MP4 路径；官方加速域名也不自动放行，因为域名不能证明境内处理。后续真实样例若返回其他域名，先核对地域再扩展确定性白名单。该白名单是项目隐私约束，不是供应商完整域名清单，也不构成 DNS 安全验证。

下载只写服务端确定的独立目录，流式计数不超过 100 MiB，检查声明大小与实际大小、截止时间；通过原有 MP4 文件头与 ffprobe 校验，再以独占发布、文件／目录同步保存。失败清理临时文件、保留旧结果；重启发现已发布结果先校验复用，避免重复下载。结果保存摘要、大小、宽高和真实本地时长，演练用量与视频时长分别显示。

## 持久化及操作合同

新增严格 schema 1 replay.json，仅存演练场景、状态、平台 ID、输入摘要、检查点、次数、错误 code、人工用量、结果元数据；不存正文、图片 Base64、签名 URL、密钥或原始错误。使用现有 atomic_write_session、目录同步、POSIX 文件锁与严格 read_document。损坏／未来 schema／重复字段／链接失败时保留原文件，返回安全错误。

新增根命令 `python3.12 scripts/project.py wan-replay --scenario success|lost-submit|query-timeout|bad-video --action step|status`。根入口固定保存到已忽略 data/wan-protocol-replay/{scenario}/，每次进程独立；status 只读、不推进。输出只含 JSON 摘要，含 simulation_only=true、network_used=false、real_execution_allowed=false、unknown 费用；错误统一 `{"error":{"code","message"}}`。没有新增 HTTP 接口，也没有用户可传的 Key、URL 或执行开关。
