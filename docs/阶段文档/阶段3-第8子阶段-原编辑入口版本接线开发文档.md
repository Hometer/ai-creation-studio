# 阶段 3 第 8 子阶段 · 原编辑入口版本接线

日期：2026-10-05。产品经理授权继续下一步，按先文档、开发、验证、提交执行。本文件在本轮代码修改之前建立。

## 目标与范围
原剧本／分镜页保留结构与 JSON 编辑，手动保存改走本地文字版本服务：开始编辑读取真实内容与修订依据，预览全量差异及受影响镜头，明确确认后原子保存并归档，可从版本页恢复。修复分镜映射遗漏未知字段、无效 JSON 静默回退及失败提前关闭草稿。

仅接原页面两个手动编辑按钮。旧介入 API、智能续写、模型生成、通用产物补丁与其他阶段仍兼容；这些外部入口的逐次自动归档、完整对话、影响处置在后续切片。本轮不收费、不调用模型、不创建云资源，不代表正式阶段或业务验收完成。

## 用户流程与页面状态
项目进入剧本／分镜 → 编辑（只读读取当前正文） → 原表单或 JSON 修改 → 保存修改（仅预览） → 核对旧／新内容及影响 → 勾选确认 → 保存为新版本 → 留在原页面并可打开文字版本。

读取中禁止提交，读取失败不开始空白编辑。预览或保存失败保留全部草稿；409、回复丢失、服务故障冻结写入，用户主动重新核对后才能重新预览。重复点击由同步锁及后端请求编号限制；不自动重发 POST。无效 JSON 明确显示错误，不能偷偷保存另一份内容。编辑中离开需提醒；项目／阶段切换仍需确认，重新载入只恢复已保存正文，未保存浏览器草稿不持久化。

## 适配与接口契约
沿用 Next.js、TypeScript、Tailwind 和既有页面，新增小型共享手动保存面板，无技术替换或新增服务费用。
- GET /api/project/{id}/content-revisions/editor/{stage}：返回 workspace 和所选阶段完整 artifact；只读、与 token 在同一锁内读取，内容超过 2 MiB 或结构不支持时拒绝。stage 限剧本与分镜。
- 已有 POST /content-revisions/preview 与 POST /content-revisions：新增互斥 replacement 对象操作，path/value、restore、replacement 必须三选一；兼容上一轮请求。replacement 为本阶段完整 JSON 对象，保留未编辑字段，校验已知编辑结构、有限深度与大小、有限数值，不允许借编辑修改运行控制／外层元数据。
- 保存仍需 expected_token、服务端 preview_token、32 位 request_id 和严格布尔 acknowledged=true；成功 201 返回 version_id、workspace 和实际当前 artifact。已保存请求幂等，变更依据不符 409，格式／无变化 422，缺失 404，存储损坏／保存失败 503。统一 error.code/message，不泄露正文和堆栈。
- 保持 source=edit 的历史协议；结构增删完整记录差异。恢复仍追加版本，不删历史。版本与正文同文件原子写；失败回滚内存。

## 数据与影响边界
分镜结构编辑复制完整 episode，不再用展示映射覆盖原文，root 或旧 payload 包裹保持原结构。剧本保留根 metadata，分镜保留 episode／segment／shot 附加字段。JSON 模式允许既有正文结构编辑，已存在的根运行元数据只能保持原值；已知表单结构校验在后端实施。已有角色／媒体／计划／预算／任务不自动更新；编辑页面说明旧媒体及其绑定保持，影响列表只是待人工核对，不代表完成重生成。历史无损归档供恢复。

## 验收与证据计划
后端覆盖多字段及结构编辑、保留元数据、增删镜头、严格协议／结构、过期预览、并发、幂等、失败回滚与重启恢复；旧接口及全量测试回归。前端覆盖真实 HTTP 契约、批量预览一致性与失联不重发，类型／Lint／生产构建。
使用 ego-browser 实际原入口闭环、JSON 错误、结构字段保留、冲突／断线保留草稿、刷新及版本恢复；390／768／1280／1440 宽度，桌面／手机截图逐张查看。人工样例独立数据服务不含模型执行接口。原业务文件哈希核对，秘密与产物扫描。README、项目状态与十项闸门写入证据包 docs/evidence/阶段3/原编辑入口版本接线/。

## 风险与回退
大对象或不支持结构明确拒绝，不截断、迁移或覆盖；原项目及旧功能不删除。整体真实模型、真机、登录隔离与业务标准继续待验；本轮只报告工程交付。仅本地 Git 提交，不推送。
