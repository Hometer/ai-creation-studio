# 映序｜AIGC 视频创作与任务编排 Agent

AI 产品经理｜Avenloop AI｜AI 视频创作工作台

**项目背景**

面向独立短片、短剧创作者，解决素材分散、角色与场景版本不一致、上游修改导致下游返工等问题，构建从脚本、资产、分镜到生成、审核与导出的创作流程。

**核心职责**

- **AIGC 产品规划与创作流程设计** 负责需求拆解、功能范围、交互设计及交付验收。针对反复生成、修改影响难以定位的问题，优先设计资产管理和生成计划，明确各阶段的输入、操作与交付要求。
- **生成素材版本与上下文管理** 建立角色、场景及媒体的版本关系，将生成计划绑定具体素材版本；支持查看变更影响、保留旧版本和主动升级，帮助创作者定位受影响的分镜与任务。
- **Agent 任务编排与人工确认** 设计计划提交、费用确认、生成执行和结果审核流程。素材引用升级后，原计划失效并需重新确认，确保生成依据、执行范围与用户选择一致。
- **AI 生成质量评测与任务恢复** 围绕角色一致性、场景连续性和分镜符合度建立审核标准，将失败案例关联至素材约束和生成计划；针对重复提交、失败重试及任务中断保留已完成结果，支持局部修改与恢复执行。
- **AI Coding 实现与交付验收** 借助 AI Coding 实现媒体归档、版本引用和任务状态管理，完成 **3 类视频输入**的计划适配；组织正常流程与异常场景验收，检查素材、计划及生成结果的关联。

**项目成果**

面向短片与短剧创作者，将单条可交付视频的制作耗时从 13 小时缩短至 4 小时，平均修改轮次从 4 轮减少至 2 轮；在团队人数不变的情况下，月均合格视频交付量从 8 条提高至 16 条，单条视频平均制作成本从 400 元降至 200 元。
